FileUpload takes `preview="image"`, `previewAlt` and `changeLabel` (GAP-270): one image, for a client's logo or a profile picture. Until one is chosen it is the drop area; once one is, the drop area gives way to the image as an avatar-sized thumbnail (40, round, as Avatar) beside its name and size, with an outline Change button that opens the picker again and the remove button, which brings the drop area back. It holds one file whatever `multiple` and `maxFiles` say, takes `image/*` unless `accept` says otherwise, and turns away a file that is not an image ("acme.pdf is not an image.") as it turns away one over `maxSize`, keeping the image it shows; a drop skips the picker's `accept`, so this is checked on every pick. The thumbnail's alt text is `previewAlt`, the file's name when left out. Change is named `changeLabel` and the file's name ("Change: acme.png"), as Remove is named `removeLabel` and the file's name; the field's label names Change once it holds the field. Focus moves to Change once an image is chosen and back to the drop area once it is removed, since the control it was on is gone. The thumbnail is an object URL, made after render (none on a server) and revoked when the image changes or the part goes. Without `preview` FileUpload is unchanged. The stylesheet gains the utilities the thumbnail draws with, so `@kozmos-ds/styles` is named too.
