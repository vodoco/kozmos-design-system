`TabsTrigger` takes an `icon`, and `SelectItem` a `count` (decision 132).

- **`TabsTrigger` `icon`** (GAP-152): the icon is drawn 20px, 4px over the tab's words, both centred and in the words' colour, so a tab of 6 + 20 + 4 + 20 + 6 is 56 tall. The list grows to hold it, 64 where it was 40, and once one tab in a list has an icon every tab in it takes that height, so the raised segment (decision 65) fills the track whichever tab is active and a tab of words alone centres them. A list of words alone keeps its 40. The list's own height and alignment are written so a height class you give `TabsList` still wins. The icon is `aria-hidden`: the tab is named by its words. An `asChild` tab stays your element, with the icon inside it. The stack is symmetric, so it reads the same right to left. Without an icon a tab renders exactly as before.
- **`SelectItem` `count`** (GAP-164): a neutral `Counter` at the option's end. **Every Select row, with a count or without, now keeps the check's 16px place at its end** (16 and the 8 gap before it), chosen or not, so counts form one column that a new choice never moves. A list sized by its content is up to 24px wider than before, the chosen row no longer changes the list's width, and long option words wrap or truncate 24px sooner near the screen's edge (LanguageSwitcher's language names among them). The count sits outside the item text, which the closed select repeats, so the closed select shows the option's words alone. A number is written in the app's grouping, from the document's `lang` as Calendar reads it ("1,234"; "1.234" in German; a server writes en-US until the client renders), and the option is named by its words, then its count: "POI, 96", the same form when the words are not plain text. An `aria-label` you give the item now names it, with a count or without; before, Radix's `aria-labelledby` outranked it. Without a count an option is named as before.

The stylesheet gains the list's two zero-specificity rules, `[:where(&:not(:has([data-slot=tabs-trigger-icon])))]:h-10` and `…:items-center`, in place of `h-10 items-center`. SwiftUI's `KozmosTabsTrigger(value:title:selection:icon:)` and `KozmosSelectItem(value:label:count:selection:)`, and Compose's `KozmosTabsTrigger(..., icon = { })` and `KozmosSelectItem(..., count = …)`, are the same parts on the other platforms. In Figma, Tabs gains a `Content` axis (`Label`, `Icon Over Label`) and `Tab 1 Icon` to `Tab 4 Icon`, and Select a `Content` axis (`Closed`, `Open`, the open list at State=Default only) whose open list shows `Option N Text` with `Option N Count` under `Show Counts`.
