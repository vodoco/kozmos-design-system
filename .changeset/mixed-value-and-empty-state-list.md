A mixed value on Input, NumberInput, Select and Combobox, and a list in EmptyState (GAP-153, GAP-165; decision 132).

- **A field can stand for several values at once (GAP-153)**, as a property of a multi-selection whose features differ. `mixed` shows none of the field's own value and "Multiple values" (`mixedLabel`) in its place, as the placeholder, and the field is described with it (`aria-describedby`), so a screen reader says it. It is controlled, as the selection is the product's: the visitor's first edit comes through the field's own change callback (`onChange`, `onValueChange`), and the product clears `mixed`, so the field keeps its mixed state until it is edited. `onResetMixed`, given for a field whose values differ, draws "Reset to multiple values" (`resetMixedLabel`) under the field once it is no longer mixed, never while it is disabled or read-only; pressed, focus returns to the field and the product drops the edit and sets `mixed` again. An uncontrolled Input or NumberInput drops its default value while mixed and empties its text on reset.
  - Input, NumberInput and Combobox take the four props. A mixed Combobox checks no option and shows no choice, though the visitor may still type a query; a choice is the edit, and the reset empties the text with the choice.
  - Select takes them on its root, which holds the value: mixed, it is given no value, so `SelectValue` shows the mixed label and no option is checked, and `SelectTrigger` is described with it and draws the reset. A mixed Select is controlled. `SelectProps` is exported, and `SelectTrigger` now always carries an `id` (yours, or one of its own) so focus can return to it.
  - `FieldWrapper` takes `mixed`, `mixedLabel`, `mixedId`, `onResetMixed` and `resetMixedLabel`, which the fields use; `MixedValueProps` is the four a field takes.
- **EmptyState takes `list` (GAP-165):** items drawn as a bulleted list under the description, from its leading edge in the 280 column, above any progress and the action, and read in order as a list of so many items; `listLabel` names it. Each item is a line of text or the product's own inline content, such as a Link. An empty list draws nothing.

`@kozmos-ds/styles` gains `.kozmos-field-reset`, the reset's text button, and `.kozmos-empty-state-list`. SwiftUI and Compose take the same: `mixed`, `mixedLabel`, `onResetMixed` and `resetMixedLabel` on their Input, NumberInput and Combobox, on Compose's `KozmosSelectTrigger`, and on SwiftUI's `KozmosSelect`, which gains `KozmosSelectField`, the closed field it draws from `KozmosSelect(value:placeholder:…)`; `list` and `listLabel` on EmptyState. The Figma importer paints State=Mixed and a Reset Mixed boolean on the Input, NumberInput, Combobox and Select sets, and a List boolean with List Item 1–3 Text on EmptyState; Code Connect maps them on all three platforms. Vue's bridge takes `mixed` as a boolean and `@reset-mixed`.
