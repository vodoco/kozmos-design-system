The stylesheet is 0.66 KB smaller gzip, and 7,255 bytes smaller raw, before what this release adds. Every Kozmos part draws as it did, and no element Kozmos renders carries what went. What a product could notice:

- **55 utilities nothing in Kozmos uses are gone.** A class a product passes through `className` applies only if Kozmos's stylesheet has it, and these it no longer has. Tailwind made them because it read Kozmos's own CSS files, from each class an `@apply` names and from property names such as `flex-shrink`, and it no longer reads those files. A product that uses one needs its own Tailwind or its own CSS: `h-control`, `h-control-sm` and `h-control-lg` read `--density-control-height-md`, `--density-control-height-sm` and `--density-control-height-lg`.
  - the plain ones: `animate-spin`, `backdrop-filter`, `border-collapse`, `border-none`, `border-y`, `drop-shadow`, `flex-shrink`, `h-control`, `h-control-lg`, `h-control-sm`, `left-2`, `outline-2`, `outline-offset-2`, `outline-ring`, `pe-16`, `ps-9`, `rounded-e-control`, `rounded-s-control`, `transition-[max-width,opacity,margin]`, `transition-[max-width,padding,background-color,color]`;
  - the colours of Button's recipes, and one surface: `bg-[var(--components-primary-buttons-danger-button-background-idle)]`, `bg-[var(--components-primary-buttons-neutral-button-background-idle)]`, `bg-[var(--components-primary-buttons-themed-button-background-idle)]`, `bg-[var(--kz-button-bg)]`, `bg-[var(--primitives-colors-background-200)]`, `border-[var(--components-secondary-buttons-themed-button-foreground-content-idle)]`, `border-[var(--kz-button-fg)]`, `text-[var(--components-primary-buttons-danger-button-foreground-content-idle)]`, `text-[var(--components-primary-buttons-neutral-button-foreground-content-idle)]`, `text-[var(--components-primary-buttons-themed-button-foreground-content-idle)]`, `text-[var(--components-secondary-buttons-themed-button-foreground-content-idle)]`, `text-[var(--kz-button-fg)]`;
  - hover, focus and pressed: `active:bg-[var(--components-primary-buttons-danger-button-background-pressed)]`, `active:bg-[var(--components-primary-buttons-neutral-button-background-pressed)]`, `active:bg-[var(--components-primary-buttons-themed-button-background-pressed)]`, `active:bg-[var(--kz-button-bg-pressed)]`, `active:scale-[0.98]`, `focus-visible:bg-[var(--components-primary-buttons-danger-button-background-focus)]`, `focus-visible:bg-[var(--components-primary-buttons-neutral-button-background-focus)]`, `focus-visible:bg-[var(--components-primary-buttons-themed-button-background-focus)]`, `focus-visible:bg-[var(--kz-button-bg-focus)]`, `hover:bg-[var(--components-primary-buttons-danger-button-background-hover)]`, `hover:bg-[var(--components-primary-buttons-neutral-button-background-hover)]`, `hover:bg-[var(--kz-button-bg-hover)]`, `hover:border-[var(--components-secondary-buttons-themed-button-foreground-content-hover)]`, `hover:border-[var(--kz-button-fg-hover)]`, `hover:text-[var(--components-secondary-buttons-themed-button-foreground-content-hover)]`, `hover:text-[var(--kz-button-fg-hover)]`;
  - file and placeholder: `file:bg-transparent`, `file:border-0`, `file:font-medium`, `file:text-sm`, `disabled:placeholder:text-muted-foreground`, `placeholder:text-[color:var(--primitives-colors-foreground-400)]`, `placeholder:text-destructive/60`.
- **`--tw-drop-shadow`.** The stylesheet registers 16 of Tailwind's compiler variables, down from 17: `drop-shadow` was the only rule that set or read this one.
- **Value text.** `var( --x )` and `calc(a * b)` are written `var(--x)` and `calc(a*b)` in ordinary declarations. `+` and `-` keep their spaces, and strings and `url()` are left as they are. Every value computes as it did; only a tool that reads `style.css` as text sees the difference.
