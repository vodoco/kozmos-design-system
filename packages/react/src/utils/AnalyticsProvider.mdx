# AnalyticsProvider

Kozmos parts report what people do with them, such as a switch being toggled or a result being opened.
A provider collects those events and hands them to your `onDispatch` in batches, for you to send where
you like. In React it is `AnalyticsProvider`; in SwiftUI, the `.kozmosAnalytics(batchDelayMs:onDispatch:)`
modifier.

## Batches

- A batch opens with an event and is delivered `batchDelayMs` after it, 2000 by default, with every event
  sent meanwhile, in the order they were sent. A later event does not move the delivery, so a steady
  stream arrives every `batchDelayMs`, not when it stops.
- What is still waiting when the provider goes away is delivered then: when `AnalyticsProvider` unmounts,
  and when the view with `.kozmosAnalytics` leaves the hierarchy. Neither delivers early when the page is
  hidden or the app moves to the background.
- A provider takes the events of the parts inside it. A nested provider takes its own subtree's, and the
  one above it gets none of them.
- An event carries `component`, `eventName`, `properties` and `timestamp`: milliseconds since 1970 in
  React, seconds in SwiftUI.
- SwiftUI calls `onDispatch` on the main thread. A SwiftUI product can add its own events to the batches
  through `@EnvironmentObject var analytics: KozmosAnalytics` and its `trackEvent`.

With no provider, React drops the events and warns once in a development build, and SwiftUI prints each
one. A SwiftUI tracker set with `.environment(\.kozmosAnalytics) { event in … }` gets each event as it
happens, unbatched.

## Compose

Compose has no batching provider. A tracker provided through `LocalKozmosAnalytics` gets each event as it
happens; a product that wants batches collects them itself. Its event has no `timestamp`, and its
`properties` are strings.

<PlatformSnippets
    react={`
import type { ReactNode } from "react";
import { AnalyticsProvider } from "@kozmos-ds/react";

declare function send(events: readonly unknown[]): void;

export function App({ children }: { children: ReactNode }) {
  // Interaction events arrive in batches, every 2000ms by default.
  return (
    <AnalyticsProvider onDispatch={(events) => send(events)}>
      {children}
    </AnalyticsProvider>
  );
}
    `}
    swift={`
import SwiftUI
import Kozmos

// The events of the parts inside arrive in batches, each 2000ms after its
// first event by default, and what is left when this view leaves the
// hierarchy. onDispatch is called on the main thread.
struct TrackedApp<Content: View>: View {
    let send: ([KozmosAnalyticsEvent]) -> Void
    @ViewBuilder let content: Content

    var body: some View {
        content.kozmosAnalytics(onDispatch: send)
    }
}
    `}
    kotlin={`
import androidx.compose.runtime.Composable
import androidx.compose.runtime.CompositionLocalProvider
import com.kozmos.providers.KozmosAnalyticsEvent
import com.kozmos.providers.LocalKozmosAnalytics

// Compose has no batching provider: the tracker gets each event of the
// parts inside as it happens.
@Composable
fun TrackedApp(send: (KozmosAnalyticsEvent) -> Unit, content: @Composable () -> Unit) {
    CompositionLocalProvider(LocalKozmosAnalytics provides { event -> send(event) }) {
        content()
    }
}
    `}
/>
