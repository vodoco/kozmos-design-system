# List

A bordered vertical list with standard or compact row density.
Compose ListItem children for content rows; use POIResultList for SDK search results and their selection/action contract.

## Rows with slots

A ListItem takes slots (GAP-195, decision 135): `leading` at the start, centred on the title's line; `title`, with
`titleAddon` beside it; `description` and `meta` under it; and `trailing`, the row's one control, at the end. Give
any of them and the row draws them; give none and the row is its children, as before. `selected` tints the row,
theme 0, for a row whose box is ticked: it is drawn only, and the row's control still says it is checked.

The Get started checklist is a List of these rows. `ListItemStatus` is its status mark: done, in progress or not
started, drawn as Stepper's step marks at 20 and read in words ("Done", or the product's own `label`). It is first in
the row, so a screen reader hears each tour's status with its name.

Pointr Cloud's Map Persona Visibility list is the same row: a persona's mark, its name, an info button beside it and
a checkbox at the end, tinted while it is ticked. The mark here is a stand-in for the persona's own (GAP-106).

import com.kozmos.components.list.KozmosListItem

@Composable
fun PlaceList() {
    KozmosList {
        KozmosListItem(text = "Reception")
