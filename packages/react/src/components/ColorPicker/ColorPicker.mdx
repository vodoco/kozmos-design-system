# ColorPicker

A colour field with a swatch trigger, a palette of presets, an alpha slider, and
a switchable text format.

## Usage

Use it where a user authors a colour:

- Theming and branding settings
- Map and layer styling
- Any editor where an arbitrary colour is a valid input

Supply `presets` wherever the palette is really constrained. A brand editor with
eight approved colours should offer those eight rather than the full spectrum —
presets make the sanctioned choice the easy one.

`format` switches how the value is written (hex, rgb, hsl) without changing the
colour. Treat it as a display preference, not as data; persist the value, not
the format the user happened to be viewing.

Alpha is separate from the colour value via `alpha` / `onAlphaChange`, so a
surface that does not support transparency can simply ignore it.

## Accessibility

- The value is always editable as text, so the picker never depends on
  hitting a target in a gradient — the one path a colour control must not
  require.
- Presets are buttons with accessible names, not bare swatches.
- `paletteLabel` names the preset group so it is not announced as a row of
  unlabelled buttons.
- Colour alone never conveys state here; `error` is a message.
