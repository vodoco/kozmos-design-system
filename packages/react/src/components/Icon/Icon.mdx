# Icon

Renders a Pointr icon supplied as a component or registry name with standard size and colour variants.
Icons are decorative by default; provide an accessible label when the icon itself conveys information.

## Names

`name` takes every name SwiftUI's and Compose's `KozmosIcon` take, the same on all three platforms:

- the curated library's names, with their aliases (`close` for `x-close`, `search` for `search-md` and the rest), each a
  Pointr Icon Library outline or a taxonomy symbol, which the Figma Icons page and Code Connect pair name for name;
- the 23 wayfinding glyphs of Pointr Maps - Express, by the kebab case of their export names: `elevator-up`,
  `stairs-no-direction`, `route-entrance-exit`, `security-control`, `shuttle` and the rest, filled in the text's colour;
- four Pointr Icon Library outlines beyond the curated set: `log-in-01`, `log-out-01`, `arrow-up-right` and
  `arrow-down-right`;
- the map controls' layers glyph and walking figure: `layers-three-01`, a Pointr Icon Library outline, and `walking`,
  the SDK's solid figure, by the kebab case of its export `Walking`.

`kozmosIconNames` lists the curated names and `kozmosIconNamesBeyondTheLibrary` the other 29. A name Kozmos does not
know draws nothing. `icon` takes any component `@kozmos-ds/icons` exports, the whole Pointr Icon Library included.

import com.kozmos.components.icon.KozmosIconColor
