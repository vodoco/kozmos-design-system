# PasswordInput

A text input for secrets, with a toggle that reveals what has been typed.

## Usage

Use it wherever a password is entered:

- Sign-in and registration forms
- Change-password and re-authentication flows
- Any field holding a secret the user may need to check before submitting

The reveal toggle is on by default. Turn it off with `showToggle={false}` only
where a shoulder-surfing risk outweighs the usability gain — a shared kiosk, for
instance.

Keep `showPasswordLabel` and `hidePasswordLabel` localized. They are the
toggle's accessible name, so a screen reader announces the action rather than an
unlabelled button.

## Accessibility

- The toggle is a button with its own accessible name, not an icon alone.
- Toggling reveals the value in place; focus and caret position are preserved so
  a keyboard user does not lose their spot.
- `error` is associated with the field, so the message is announced rather than
  conveyed by colour alone.
