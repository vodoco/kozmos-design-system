# DirectionStep

A step of a route: the symbol, instruction and optional distance and duration. The shared `DirectionKind` vocabulary includes `straight`, `left`, `right`, `destination`, `walking`, `turn-back`, `enter`, `exit`, same-level `transition`, unnamed `level-up` / `level-down`, and explicit `lift`, `stairs`, `escalator` and `ramp` up/down pairs. Choose the actual route instruction, not a generic arrow that hides its transport mode.

Turns, turning back, the destination, lifts, escalators, stairs, ramps, entry and exit draw Pointr's own wayfinding artwork from the Pointr Maps - Express design (Figma `BwtG2COVRqUWGPrIvP4jxr`, Wayfinding Icons), as solid shapes in the text colour: HardLeft, HardRight, TurnBack and Arriving for the first four. Straight on, level changes and transitions, which that set has no glyph for, keep the Pointr icon set's arrows, and walking the existing SDK mark on web and platform walking symbols on native. One source, `packages/icons/src/owned/navigation-glyphs.json`, generates the artwork for all three platforms. Express's Exit was Entrance mirrored, an arrow going into a door; Kozmos's keeps Entrance's door and points the arrow away from it. Every Express glyph is also there by name: `@kozmos-ds/icons` exports each (the defaults' and `ElevatorUpAndDown`, `EscalatorNoDirection`, `StairsNoDirection`, `RampNoDirection`, `RouteEntranceExit`, `FollowTheLine`, `CustomTransition`, `SecurityControl` and `Shuttle`), and `KozmosIcon` on iOS and Android draws each by its kebab-case name; the Glyph Atlas story shows them all. Physical direction does not mirror in RTL; text layout does. Symbols are decorative: assistive technology hears the supplied instruction.

The old `DirectionType` name remains a source alias. Native consumers must rebuild; the enum identity has moved to the shared contracts, and exhaustive switches need the added cases. Swift raw-value initialization and Kotlin `KozmosDirectionKind.fromValue` allow adapters to reject unknown values. Unknown runtime web values omit the symbol and retain the instruction rather than invent a turn. The host must decide whether an unknown route instruction is safe to present.

Regenerate with `pnpm icons:navigation:generate`; verify with `pnpm icons:navigation:check`. Do not edit generated TS, Swift or Kotlin paths. The atlas shows 14, 24 and 32 pixel sizes; a physical-device legibility check remains separate.

## Ordered instruction parts

Distance and duration are independently optional localized labels. Either can appear alone; when both are present they are joined with a separator. Empty labels are omitted, but a supplied zero-valued label such as `0 min` is retained. The component does not calculate or infer metrics.

Pass a string as before, or an ordered array of `{ text, role?, lang? }`.
Include whitespace and punctuation in `text`. The optional `secondary` role is a
muted, regular-weight qualifier at the same size (full foreground on glass for contrast); `lang` supplies a BCP 47 speech
language for a foreign landmark. The sentence keeps its supplied word order and
wraps as one inline flow. iOS and Android accept `[KozmosInstructionPart]` and
`List<KozmosInstructionPart>` respectively; old String calls remain supported.
All three renderers preserve speech-language metadata rather than flattening it
into a replacement accessible label. Physical speech acceptance remains separate.
