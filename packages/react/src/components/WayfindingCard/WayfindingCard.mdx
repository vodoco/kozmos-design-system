# WayfindingCard

Displays route-planning content with an optional close action. Localize
`closeLabel` when providing `onClose`. `WayfindingInputRow` supports
`originLabel`, `destinationLabel` and `swapLabel`; placeholders are hints, not
replacements for those accessible names. Navigation actions do not submit a
surrounding form.

## Implementation

Close and swap use actual 44px/44pt targets on web/iOS and 48dp on Android. The input text reserves space beside the enlarged swap control. SwiftUI also accepts `closeLabel`; Compose currently uses its built-in Close label.
