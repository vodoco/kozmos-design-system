# Rating

Collects or displays a rating using stars or a thumbs-up/down choice.
Use `value` and `onChange` for input, `readOnly` for display, and the label props to provide localized accessible names.

## Read-only halves

A read-only star rating shows a score to the nearest half: an average of reviews is rarely whole.
The value is rounded half up on its double, `Math.round(value * 2) / 2`, so 4.3 draws as 4.5, 4.2 as 4 and 4.25 as 4.5.
The accessible name states the rounded value, "Rated 4.5 out of 5 stars", and `valueLabel` is given it.
The half is the filled star clipped to its inline start, the right half in a right-to-left page.
Editing stays whole stars. SwiftUI's `KozmosRating(rating:)` and Compose's `KozmosRating(rating = …)` take the score.

import { useState } from "react";

import { KozmosRating } from "@kozmos-ds/vue/react-bridge"

</template>
    `}
    swift={`
import SwiftUI
import Kozmos

// 0 is unrated, and choosing the chosen star clears it. label is the
// group's name for VoiceOver, as aria-label is on the web.
struct RateYourVisit: View {
    @State private var rating = 0

    var body: some View {
        KozmosRating(value: $rating, label: "Rate your visit")
    }
}
`}
    kotlin={`
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableIntStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import com.kozmos.components.rating.KozmosRating

// 0 is unrated, and choosing the chosen star clears it. label is the
// group's name for TalkBack, as aria-label is on the web.
@Composable
fun RateYourVisit() {
    var rating by remember { mutableIntStateOf(0) }
    KozmosRating(value = rating, onValueChange = { rating = it }, label = "Rate your visit")
}
`}
