# Text

Applies Kozmos typography, colour, alignment and optional truncation to body text.
Choose a semantic element with `as`, or use Heading for a heading with a level-based type scale.

## Display size

`size="display"` is the one display size, 48 on 54 lines (decision 203, GAP-272), for a marketing-style headline or a figure that leads a page. It is bold from its own token unless `weight` is given. The values come from the display type tokens, in rem, so it follows the reader's text size. For a headline that is a heading, use Heading's `size="display"`, which keeps its level. SwiftUI's `KozmosText(style: .display)` is 48pt bold on 54pt lines and grows with Dynamic Type; Compose's `KozmosTextStyle.Display` is `KozmosTypography.display`, 48sp on 54sp. Figma's Text has Size=Display, and its text styles are Text / Display / Normal to Bold.

import { Text } from "@kozmos-ds/react";
export function Example() {
  return (
    <>
      <Text>Find your way to reception.</Text>
    </>
  );

    `}
    vue={`
<script setup>
import { KozmosText } from "@kozmos-ds/vue/react-bridge"
</script>

<template>
  <KozmosText />
</template>
    `}
    swift={`
import SwiftUI
import Kozmos

// Body text on the type ramp. style and tone name a step and a purpose,
// such as .footnote and .muted, rather than a font and a colour.
struct ReceptionHint: View {
    var body: some View {
        KozmosText("Find your way to reception.")
    }
}
`}
    kotlin={`
import androidx.compose.runtime.Composable
import com.kozmos.components.text.KozmosText

// Body text. style names a step on the type ramp, such as
// KozmosTextStyle.Footnote, as SwiftUI's does; left out, the words draw in
// the style around them. Compose's KozmosText has no tone or truncation.
@Composable
fun ReceptionHint() {
    KozmosText(text = "Find your way to reception.")
}
`}
