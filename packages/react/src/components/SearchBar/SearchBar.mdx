# SearchBar

A search row with a controlled query, clear action and an optional trailing control.
Its floating variant supplies the surface styling; the host or MapOverlay owns placement and search-result behaviour.

On React, the clear action composes Core IconButton. It keeps a 44px target and
a decorative 24px mark, uses `clearLabel` as its accessible name, and does not
submit a surrounding form. `disabled` and `readOnly` also disable clearing.
Enabled clearing calls `onChange("")` and `onClear` once; the usual Core Button
analytics event accompanies SearchBar's `search_cleared` event. The decorated
input itself still awaits the shared Core field-composition capability.

Clearing returns focus to the input before calling the host, so `onClear` may
deliberately move focus elsewhere. Forwarded refs still expose the input. Host
`onKeyDown` handlers run first; prevented or IME-composing Enter events do not
emit `search_initiated`.

    react={`
import { SearchBar } from "@kozmos-ds/react";
export function Example() {
  return (
    <>
      <SearchBar aria-label="Search places" />
    </>
  );
}

    vue={`
<script setup>
import { KozmosSearchBar } from "@kozmos-ds/vue"
</script>

<template>
  <KozmosSearchBar />
</template>
    `}
    swift={`
import SwiftUI
import Kozmos

// The placeholder is also the field's spoken name. The clear button empties
// the query, then calls onClear if there is one.
struct PlaceSearch: View {
    @Binding var query: String

    var body: some View {
        KozmosSearchBar(text: $query, placeholder: "Search places")
    }
}
`}
    kotlin={`
import androidx.compose.runtime.Composable
import com.kozmos.components.searchbar.KozmosSearchBar

// The placeholder is also the field's spoken name. The clear button shows
// only with an onClear, and it is onClear that empties the query.
@Composable
fun PlaceSearch(query: String, onQueryChange: (String) -> Unit) {
    KozmosSearchBar(
        value = query,
        onValueChange = onQueryChange,
        onClear = { onQueryChange("") },
        placeholder = "Search places"
    )
}
`}

/>
