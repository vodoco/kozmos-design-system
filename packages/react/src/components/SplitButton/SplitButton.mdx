# SplitButton

Pairs a primary action with a separate dropdown of related actions.
Supply `onMainClick` for the primary button and `menuItems` for the alternatives; `disabled` applies to both triggers.
The menu half shows only a chevron and is named by `menuLabel`, "More options" by default, on the web, SwiftUI and
Compose; a product that translates passes its own.

Both halves are the theme fill, and each draws the pressed token, `#0D44C2`, while it is held, on
the web and in Compose. On iOS the menu half keeps SwiftUI's own press: it is a `Menu`, which does
not run a custom button style's pressed state, and drawing the token there would mean replacing the
system menu. This is a deliberate platform difference (decision 64); the action half draws the token
on iOS too.

## Menu items

The menu takes Menu's items (GAP-168, decision 209). Each of `menuItems` is an action, `{ label, onClick }`, with an
`icon` drawn before its words and hidden from its name, or `disabled`, said disabled, drawn at half and skipped by the
arrow keys; `{ type: "separator" }` draws a line between groups. `menuContent` is custom content after them, Menu's own
parts: `MenuLabel`, `MenuItem`, `MenuCheckboxItem`, `MenuSeparator`. `SplitButtonProps` and the item types are exported
from the package.

SwiftUI's `KozmosSplitButton(label:mainAction:items:)` takes `.action(_:icon:disabled:action:)` and `.separator`, and a
`menuContent` view builder for what the system's `Menu` holds. Compose's `menuItems` take `SplitContextMenuItem`'s
`icon` and `enabled`, and `SplitContextMenuSeparator`; `menuContent` draws after them and is given the function that
closes the menu. The `(title, action)` and `SplitContextMenuItem(label) { … }` items are as they were. In Figma, Menu Open
shows the open menu under an enabled variant.

import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Download
import androidx.compose.material3.DropdownMenuItem
import androidx.compose.material3.Icon
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import com.kozmos.components.splitbutton.KozmosSplitButton
import com.kozmos.components.splitbutton.SplitContextMenuItem
import com.kozmos.components.splitbutton.SplitContextMenuSeparator

// An item takes an icon and enabled; a separator draws a line; menuContent
// follows them and is given the function that closes the menu.
@Composable
fun PublishTargets(publish: (String) -> Unit) {
    KozmosSplitButton(
        label = "Publish",
        onMainClick = { publish("draft") },
        menuItems = listOf(
            SplitContextMenuItem(
                label = "Publish to staging",
                icon = { Icon(Icons.Default.Download, contentDescription = null) }
            ) { publish("staging") },
            SplitContextMenuSeparator,
            SplitContextMenuItem(label = "Publish to production", enabled = false) {}
        ),
        menuContent = { close ->
            DropdownMenuItem(text = { Text("Publish tonight") }, onClick = { publish("tonight"); close() })
        }
    )
}
`}

}
