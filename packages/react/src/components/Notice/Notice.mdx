# Notice

A short notice that opens for the long version.

The full legal wording above AI-assisted results runs to four lines — 114px
above the results that are themselves the answer. Collapsed, this is one line:
an icon, a sentence worth reading on its own, and a clear affordance that there
is more. Keep the summary informative; a collapsed notice reading "Important"
tells the reader nothing.

`role="status"`, never `alert`: it must be heard when results arrive without
cutting across whatever the visitor is already being told.

The collapsed detail is hidden with the `hidden` **attribute**, not a class, so
it stays hidden when the stylesheet does not and stays out of the accessibility
tree either way.

Each tone draws its own mark: a triangle for `warning`, an info circle for `info`, an alert circle
for `critical`, a check for `success`. `icon` replaces the tone's mark; `icon={null}` draws none and leaves no empty column, so the
summary, the detail and the action start at the notice's edge. `iconAlign="center"` centres the
icon on a one-line summary that holds a control, as MAP-474's Search with AI suggestion does
(GAP-118); the default `start` keeps it on the first line of a summary that wraps.

<Canvas of={Stories.SearchWithAi} />

Set `collapsible={false}` with a `critical` tone and an `action` for an
emergency: help first, not a result list. Nobody in an emergency should have to
find a "More" link before they can act.

Expansion is uncontrolled by default and controllable, so a product can
remember it for the session — persistence belongs to the app, which knows what
storage it is allowed.

## Success, progress and done

`tone="success"` is the fourth tone (GAP-160), in the success colours: a 50% edge and a 5%
fill of success 800, its words and mark in the success text colour, Toast's check.

`status` says where the work the notice reports on has got. `"progress"` turns the system's
loading arc, Spinner's, where the mark is, still under reduced motion. The notice is not
marked `aria-busy`: on its own live region that would hold back the words that say what is
running. `"done"` draws a check at the summary's inline end, as "Geometry is set" ends,
and no mark at its start unless `icon` gives one. The marks are hidden from assistive
technology: the summary's words say what happened, and a polite notice says them as they
change.

`action` is the control under the words (GAP-033; MAP-587's "Alert action"), in every tone
and state: "Set Building Boundary" under "Set Geometry". SwiftUI's `KozmosNotice` takes it as
its trailing view builder and Compose's as `action`, with the same tones, `status`, `icon`,
`iconAlign`, `collapsible`, `expandLabel` and `live` as React. In Figma, Notice is a set of
Tone by Status, with Summary, Show Icon, Show Detail and Detail, and Show Action.

import Kozmos

// The building editor's geometry notices: a warning with its action under

    let saved: Bool
    let setBoundary: () -> Void

            KozmosNotice("Saving the geometry", tone: .info, status: .progress)
        } else {
            KozmosNotice("Set Geometry", detail: "Draw the building's outline on the map.", tone: .warning, collapsible: false) {
                KozmosButton("Set Building Boundary", variant: .outline, size: .sm, action: setBoundary)
            }
        }
    }
}
