# Navbar

Horizontal app navigation shell. Compose route items with `NavigationItem` inside the `navigation` slot, and pass product context through named slots such as `logo`, `context`, `primaryAction`, `actions`, `utilities`, and `account`.

The shell wraps according to its available width, including inside a narrow pane
on a large screen. Its minimum height is 64px, not a fixed height: context, actions,
and navigation remain available rather than disappearing at a breakpoint. Allow
the host layout to grow with it. Consumer-provided navigation groups should wrap
and should not impose fixed widths larger than their container. `navigationLabel`
names the navigation landmark (default: “Main navigation”).
