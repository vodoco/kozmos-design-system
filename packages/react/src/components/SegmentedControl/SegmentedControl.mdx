# SegmentedControl

Use SegmentedControl when users choose one option from a short, visible set.
Prefer Radio for longer lists and Tabs when the selected item changes visible
content regions.

## Holding the choice

Pressing the segment that holds the pill takes the choice back, and
`onValueChange` reports that as `undefined`. A product that holds the choice
says "nothing chosen" with `null`, so it passes `value={view ?? null}`: the
control then shows no pill, from the start and after the choice is taken back
or cleared.

```tsx
const [view, setView] = useState<string>();

<SegmentedControl items={views} onValueChange={setView} value={view ?? null} />;
```

`undefined`, or no `value` at all, leaves the choice to the control, as it
always has: a wrapper of the product's own that passes its optional `value` on
keeps working when it is used without one. Give `defaultValue` for the
control's first choice. A product that wants exactly one choice at all times
ignores the `undefined` and keeps its `value`.

<PlatformSnippets
  react={`
import { SegmentedControl } from "@kozmos-ds/react";
export function Example() {
  return (
    <>
      <SegmentedControl
        defaultValue="overview"
        items={[
          { value: "overview", label: "Overview" },
          { value: "details", label: "Details" },
          { value: "activity", label: "Activity" },
        ]}
      />
    </>
  );
}
  `}
  vue={`
<script setup>
import { KozmosSegmentedControl } from "@kozmos-ds/vue"
</script>

<template>
  <KozmosSegmentedControl />
</template>
  `}
  swift={`
@State private var selection = 0

KozmosSegmentedControl(
selection: $selection,
items: ["Overview", "Details", "Activity"]
)
`}
  kotlin={`
var selectedIndex by remember { mutableIntStateOf(0) }

KozmosSegmentedControl(
options = listOf("Overview", "Details", "Activity"),
selectedIndex = selectedIndex,
onOptionSelected = { selectedIndex = it }
)
`}
/>
