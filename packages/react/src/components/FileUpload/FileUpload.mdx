# FileUpload

A file-selection surface with browsing, drag-and-drop, selected-file removal and validation feedback.
Use its callbacks to receive files and perform uploads in the host; selecting a file does not upload it.

## Implementation

SwiftUI's and Compose's FileUpload hold one file. Picking one calls `onFileSelected`, and removing
it calls `onFileRemoved` with the same file, where React calls `onFilesChange` with the files left.
Their drop area says `browseLabel`, "Tap to upload file" by default, and their remove button is
named `removeLabel`, "Remove"; a product that translates passes its own.

import SwiftUI
import Kozmos

// One file, from the system's importer, of the types allowedContentTypes
// names (any, unless it says otherwise): no drag and drop, no second file, no
// size limit and no message. The part draws no label, so KozmosFieldWrapper
// puts one above it. Picking a file hands you its URL and uploads nothing;
// removing it hands you the same URL. browseLabel and removeLabel are its
// words, "Tap to upload file" and "Remove" unless you pass your own.
struct DocumentUpload: View {
    let receive: (URL) -> Void
    let drop: (URL) -> Void

    var body: some View {
        KozmosFieldWrapper(label: "Documents") {
            KozmosFileUpload(onFileSelected: receive, onFileRemoved: drop)
        }
    }
}
`}
    kotlin={`
import android.net.Uri
import androidx.compose.runtime.Composable
import com.kozmos.components.fieldwrapper.KozmosFieldWrapper
import com.kozmos.components.fileupload.KozmosFileUpload

// One file of any type, picked with the system's picker: no drag and drop, no
// second file, no type or size limit and no message. The part draws no label,
// so KozmosFieldWrapper puts one above it. Picking a file hands you its Uri
// and uploads nothing; removing it hands you the same Uri. browseLabel and
// removeLabel are its words, "Tap to upload file" and "Remove" unless you
// pass your own.
@Composable
fun DocumentUpload(receive: (Uri) -> Unit, drop: (Uri) -> Unit) {
    KozmosFieldWrapper(label = "Documents") {
        KozmosFileUpload(onFileRemoved = drop, onFileSelected = receive)
    }
}
`}
