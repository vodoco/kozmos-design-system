# Card

Displays a card with header, content, and footer.

`CardContent` and `CardFooter` pad their sides and bottom: a header above them has already paid the
top. With no header, the one that is the card's first child pays the top as well, so content never
touches the card's top edge (GAP-194). A part inside a wrapper, such as a `form` around the card's
parts, is not the card's first child and is left as it is.

`CardTitle` is a heading, and its level follows the page's outline (GAP-205): an `h3` unless `as`
says otherwise. Under a page titled with an `h1`, a card's title is the next level down,
`as="h2"`, or a screen reader's list of headings skips a level. `as` takes `h2` to `h6`, as
`Heading` does; there is no `h1`, the page's own title. The level changes what a screen reader
hears, not how the title looks. On SwiftUI and Compose `KozmosCardTitle` is a heading too, with no
level: VoiceOver's and TalkBack's heading navigation stop on it.

import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,

      <Card>
        <CardHeader>
          <CardTitle>Card Title</CardTitle>
          <CardDescription>Card Description</CardDescription>
        </CardHeader>
        <CardContent>
          <p>Card Content</p>

        </CardFooter>
      </Card>
    </>

}

<script setup>
import { KozmosCard } from "@kozmos-ds/vue"
// @kozmos-ds/vue wraps the Card only: it has no CardHeader, CardTitle, CardDescription, CardContent or CardFooter.
</script>

<template>
  <KozmosCard>
    <p>Card Content</p>
  </KozmosCard>
</template>

    swift={`
import SwiftUI
import Kozmos

// The header, content and footer pad themselves by the card's padding:
// KozmosCard(padding: .compact) tightens all three.
struct TitledCard: View {
    var body: some View {
        KozmosCard {
            KozmosCardHeader {
                KozmosCardTitle("Card Title")
                KozmosCardDescription("Card Description")
            }
            KozmosCardContent {
                KozmosText("Card Content")
            }
            KozmosCardFooter {
                KozmosText("Card Footer")
            }
        }
    }
}
`}
    kotlin={`
import androidx.compose.runtime.Composable
import com.kozmos.components.card.KozmosCard
import com.kozmos.components.card.KozmosCardContent
import com.kozmos.components.card.KozmosCardDescription
import com.kozmos.components.card.KozmosCardFooter
import com.kozmos.components.card.KozmosCardHeader
import com.kozmos.components.card.KozmosCardTitle
import com.kozmos.components.text.KozmosText

// The header, content and footer pad themselves by the card's padding:
// KozmosCard(padding = KozmosCardPadding.Compact) tightens all three.
@Composable
fun TitledCard() {
    KozmosCard {
        KozmosCardHeader {
            KozmosCardTitle(title = "Card Title")
            KozmosCardDescription(description = "Card Description")
        }
        KozmosCardContent {
            KozmosText(text = "Card Content")
        }
        KozmosCardFooter {
            KozmosText(text = "Card Footer")
        }
    }
}
`}
