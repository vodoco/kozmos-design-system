# Kbd

A key drawn as a key, in a hint or a list of shortcuts: "Press <kbd>Esc</kbd> to clear" (GAP-156). It is drawn as
written and read by the key's name, so a screen reader reads that hint "Press Escape to clear".

## One key or a combination

`children` is one key; `keys` is a combination, drawn as keys joined by "+" and read by each key's name:
`<Kbd keys={["Ctrl", "C"]} />` is read "Control+C". HTML writes a combination as a `<kbd>` of `<kbd>`s, and so does
Kbd.

## What it is read as

Kbd knows the names of the keys hints abbreviate or draw as symbols: Esc is read "Escape", Ctrl "Control", ⌘ "Command",
⌥ "Option", ⇧ "Shift", ↵ "Enter", ⌫ "Backspace", Del "Delete", the arrows "Up arrow" and so on. Any other key is read as
written. The names are English: pass `label`, the product's own words, to replace what is read for the whole part.

Kbd draws the key you write. It doesn't swap ⌘ for Ctrl by platform: write the key the reader presses.

import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import com.kozmos.components.kbd.KozmosKbd
import com.kozmos.components.text.KozmosText

// A key is drawn as you write it and read by its name: TalkBack reads this
// Esc as "Escape". keys = listOf("Ctrl", "K") draws a combination, read

@Composable
fun ClearSearchHint() {
    Row(
        horizontalArrangement = Arrangement.spacedBy(KozmosDimensions.primitivesLayoutSpacing50),
        verticalAlignment = Alignment.CenterVertically
    ) {
        KozmosText(text = "Press")
        KozmosKbd(key = "Esc")
        KozmosText(text = "to clear")
    }
}
