# ToggleButton

A button that maintains a pressed/unpressed choice, with default or outline styling.
Use `pressed` and `onPressedChange` for controlled state, or `defaultPressed` for an initial uncontrolled value.

## With a tooltip

A ToggleButton can be a tooltip's trigger, `TooltipTrigger asChild`, and it keeps its pressed look:
the trigger writes the tooltip's `data-state` onto the button, so the pressed fill is read from
`aria-pressed`, which no trigger touches. To restyle the pressed look, key on `aria-pressed` too.

## Mixed

With several features selected, a toggle that is pressed for some and not for others is one toggle
for all of them (decision 188). `mixed` draws a dashed edge in the theme fill on the muted fill,
with a dash before the label, Checkbox's mixed mark (decision 190), in either variant. It is
announced as mixed: `aria-pressed="mixed"` on the web, which ARIA gives a toggle button; on Compose,
TalkBack is given Compose's own mixed state, Indeterminate, said as "partially checked". iOS has no
mixed state for a button, so SwiftUI says "Multiple values" (`mixedLabel`) as its value and never
selected. A press turns it pressed: the toggle reports `true` through its change callback, and the
product clears `mixed`.

Give `onResetMixed` for a toggle whose values differ: once it is no longer mixed it draws "Reset to
multiple values" (`resetMixedLabel`), never while it is disabled. Pressed, focus goes back to the
toggle, and the product sets `mixed` again. On the web the reset is drawn after the toggle, in the
same parent, so give the pair a container, and a toggle with a reset is no `asChild` trigger. Hold
`isOn` false while mixed on SwiftUI, so the tap changes the binding.

In Figma, Mixed is a value of the State axis.

import * as React from "react";
import { ToggleButton } from "@kozmos-ds/react";

export function BoldAcrossSelection({ bold }: { bold: boolean[] }) {
  const [edit, setEdit] = React.useState<boolean>();
  const differs = bold.some((on) => on !== bold[0]);
  return (
    <div className="flex flex-col gap-1">
      <ToggleButton
        mixed={differs && edit === undefined}
        pressed={edit ?? bold[0]}
        onPressedChange={setEdit}
        onResetMixed={differs ? () => setEdit(undefined) : undefined}
      >
        Bold
      </ToggleButton>
    </div>
  );
}

const edit = ref(null)
const differs = computed(() => new Set(props.bold).size > 1)

import SwiftUI
import Kozmos

// Bold on some of the selected labels and not on others: the toggle is
// mixed until it is tapped, which turns it on and clears mixed. While mixed
// it is held off, so the tap changes it. VoiceOver says "Multiple values"
// as its value; it is never selected.
struct BoldAcrossSelection: View {
    let bold: [Bool]
    @State private var edit: Bool?

    var body: some View {
        let differs = Set(bold).count > 1
        KozmosToggleButton(
            isOn: Binding(get: { edit ?? (differs ? false : bold[0]) }, set: { edit = $0 }),
            label: "Bold",
            mixed: differs && edit == nil,
            onResetMixed: differs ? { edit = nil } : nil
        )
    }
}
`}

import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import com.kozmos.components.togglebutton.KozmosToggleButton

// Bold on some of the selected labels and not on others: the toggle is
// mixed until it is clicked, which turns it on and clears mixed. TalkBack
// hears Compose's mixed state, "partially checked".
@Composable
fun BoldAcrossSelection(bold: List<Boolean>) {
    val differs = bold.distinct().size > 1
    var edit by remember(bold) { mutableStateOf<Boolean?>(null) }
    KozmosToggleButton(
        checked = edit ?: bold.first(),
        onCheckedChange = { edit = it },
        label = "Bold",
        mixed = differs && edit == null,
        onResetMixed = if (differs) ({ edit = null }) else null
    )
}
`}
