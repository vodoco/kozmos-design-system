# MapView

A named surface that contains the map renderer supplied by the host, not a map SDK itself.
Use `framed` for a map in page flow or `fill` inside AdaptiveMapShell for an edge-to-edge surface.

## Stacking

MapView is its own stacking context, framed or filling (the site's GAP-40): what the map draws, a
`MapOverlay`'s z-index 50 or a map engine's own layers, stacks inside the map. It cannot draw over
a page's sticky header, which is z-index 50 too, or over AdaptiveMapShell's top bar, controls and
panel. A fixed overlay rendered inside the map, a `Backdrop`, a fixed `FloatingActionButton` or a
`DynamicIsland`, is held there too, under the header and the shell's chrome. Render fixed overlays
outside the map, or portal them out of it (React's `createPortal`, into a `ThemeProvider` of their
own). Popovers, tooltips, dialogs and menus already portal out.

import SwiftUI
import Kozmos

// The frame your map renderer sits in: a fill, a 1pt border, the control
// radius and a 400pt floor, always. There is no fill variant for a map that
// is the whole screen, and the frame names nothing: React's mapLabel and
// region have no counterpart.
struct FramedMap<Renderer: View>: View {
    let renderer: Renderer

    var body: some View {
        KozmosMapView {
            renderer
        }
    }
}
`}
    kotlin={`
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import com.kozmos.components.mapview.KozmosMapView

// The frame your map renderer sits in: a fill, a 1dp border, the control
// radius and a 400dp floor, always. There is no fill variant for a map that
// is the whole screen, and the frame names nothing: React's mapLabel and
// region have no counterpart. The renderer sizes itself.
@Composable
fun FramedMap(renderer: @Composable () -> Unit) {
    KozmosMapView(modifier = Modifier.fillMaxWidth()) {
        renderer()
    }
}
`}
