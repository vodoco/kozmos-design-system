# CodeBlock

A read-only block of code (GAP-216, decision 225): MAP-619's merged unit shows a custom field's JSON in one. The code is
in the mono family (Semantics / Typography / Family / Mono), 14/20 in the foreground, on the muted surface (background
100), on the control radius, 12 inside. There is no syntax colouring: the code is plain text, shown as written, every
space and line kept, and it can be selected.

<Canvas of={CodeBlockStories.Default} />

## Anatomy

- **`code`**: the text, as written.
- **`label`**: the block's name, what a screen reader says it is ("mergedUnit JSON"), in the product's words.
- **`wrap`**: long lines wrap, breaking anywhere a line has no space (the default). With `wrap={false}` each line stays
  whole and the block scrolls sideways.
- **`copyable`**: a copy at the block's top end, 4 in from its edges, the code kept clear of it. It copies the code and
  says so: "Copied" (`copiedLabel`) in a polite live region, and a check in place of the copy icon for two seconds;
  copied again, it says so again. If the browser refuses the clipboard, it says nothing. The button is named "Copy"
  (`copyLabel`); `onCopy` receives the code.

<Canvas of={CodeBlockStories.Scroll} />

## Accessibility

A CodeBlock is a region named by `label`, holding a `<pre>` and its `<code>`. Scrolling sideways, the `<pre>` is a stop
on the keyboard's way, so its overflow can be read with the arrow keys; wrapped, it never scrolls sideways and is not
one. The copy is a button of its own, after the code. SwiftUI's `KozmosCodeBlock` is a VoiceOver container named by its
label, holding the code and the copy; Compose's is a group TalkBack walks together, named by its label as a pane,
Compose's nearest to a named region. On both the copy says it copied: a VoiceOver announcement, a polite live region on
Compose.

## Not a field

A CodeBlock shows code a person reads and copies, never edits: there is no caret and nothing to type into. A value a
person edits is a Textarea.

In Figma it is the CodeBlock set: Overflow, Wrap or Scroll, Copy to show the copy, and Code Text for the code. Figma
draws the code in the Primitives mono family, Fira Mono, falling back to the UI font where the file does not have it.
