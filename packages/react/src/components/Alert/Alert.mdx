## Without a title

An icon and a description alone: the words are centred on the icon's line, with as much space below
them as above, on one line or several (GAP-269). The same on SwiftUI and Compose: one line of words
beside the icon is centred on it, and a title and its description, or a longer description, start at
the top. Right to left, the icon and the room for it are at the right, the inline start.

import SwiftUI
import Kozmos

// The icon, title and description take the alert's variant: its symbol and
// its colour. It announces nothing: it is part of the page, as React's is
// by default.
struct ClosingTimeAlert: View {
    var body: some View {
        KozmosAlert {
            KozmosAlertIcon()
            KozmosAlertContent {
                KozmosAlertTitle("Heads up!")
                KozmosAlertDescription("The venue closes at 18:00 today.")
            }
        }
    }
}
`}

import com.kozmos.components.alert.KozmosAlertDescription
import com.kozmos.components.alert.KozmosAlertIcon
import com.kozmos.components.alert.KozmosAlertTitle

// The icon, title and description take the alert's status: its icon and
