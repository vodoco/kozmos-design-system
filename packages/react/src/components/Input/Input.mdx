# Input

Inputs allow users to enter text into a UI. They typically appear in forms and dialogs.

## Usage

Use inputs to get text data from the user. Common use cases include:
- Forms (Name, Email, Password)
- Search fields
- Filtering data

## Actions

`action` puts a button inside the field's end (GAP-154), drawn as PasswordInput's reveal is: as tall
as the field, inside its border, with its own focus ring, and the field's text kept clear of it.
Hovered, it draws a fill inside itself, 4 px in from its edges (36 across in touch, 32 in compact),
its corners the field's less 4, so the field's edge stays drawn round it (decision 164); it draws
none at rest, disabled or in forced colours. It is disabled with the field.

- `{ kind: "copy" }` copies the field's value: for a value a product shows and never edits, a
  feature's ID, with `readOnly`. Once copied, a polite live region says "Copied" (`copiedLabel`),
  and a check stands in for the copy icon for two seconds; copied again, it says so again. If the
  browser refuses the clipboard, it says nothing. The button is named "Copy" (`label`); `onCopy`
  receives the value.
- `{ kind: "toggle" }` is a pressed button with its own name: the Featured star at a field's end.
  `label`, `icon`, `pressed` and `onPressedChange` are the product's. Pressed, it is drawn as a
  pressed ToggleButton is, as the MAP-64 design draws its Featured star: the theme fill under the
  icon, in the fill's foreground, in the hover fill's shape (decision 165), so the state is a shape
  and not a colour alone (WCAG 1.4.1), whatever the icon. Hovered, the fill is the themed Button's
  hover; in forced colours it is Highlight, hovered or not.

Giving a field an action, or taking it away, keeps the same input, its focus and a value typed
into it.

SwiftUI's and Compose's `KozmosInput` take `action` from 0.16.0 (decision 134):
`KozmosInputAction.copy()` and `.toggle(label:icon:isPressed:)` on SwiftUI,
`KozmosInputAction.Copy()` and `KozmosInputAction.Toggle(label, icon, pressed, onPressedChange)` on
Compose. The button is the field's 44 end, the pressed fill 36 across inside it with the control
radius less 4, and only a disabled field disables it. A copy puts the value on the pasteboard or the
clipboard and says "Copied": a VoiceOver announcement, a polite live region on Compose. A toggle's
`icon` is the product's image (`Image(systemName:)`, an `ImageVector`); pressed, it is selected to
VoiceOver and on to TalkBack. Neither platform has a pointer hover to draw.

## In Safari

`className` lands on the field. A utility class passed there styles it in Chrome, Edge,
Firefox and Safari 26.4, and is ignored in Safari 26.0 to 26.3, where the field keeps its
own look: those versions apply no `@scope` rule to an `<input>` (GAP-174), and Kozmos's
utilities are scoped. Use the props, the provider's `tokens`, an inline `style` or your
own CSS, and `wrapperClassName` for the layout around it. Guides › Platform support ›
Fields in Safari has the detail.
