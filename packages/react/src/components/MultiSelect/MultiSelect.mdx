# MultiSelect

A filterable field for choosing several options, each shown as a removable chip.

## Usage

Use it when the user picks more than one value from a long list:

- Filtering results by several categories at once
- Assigning multiple owners, tags, or amenities
- Any set-valued field where the choices are known up front

For one value use `Combobox`. For a handful of options with no filtering, a
group of `Checkbox` controls is clearer than a dropdown.

`maxSelected` caps the selection; the remaining options become unselectable
rather than disappearing, so the user can see what they are trading away.

`onValueChange` receives both the values and the matching options, so the label
for each chip does not need a second lookup.

## Accessibility

- Each chip carries its own remove button with an accessible name naming the
  value, so "Remove Food" is announced rather than "Remove".
- Backspace in an empty input removes the last chip, matching the behaviour
  keyboard users expect from token fields.
- Reaching `maxSelected` disables the remaining options rather than hiding them,
  and the limit is announced.
