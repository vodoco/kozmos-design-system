# MultiSelect

A filterable field for choosing several options, each shown as a removable chip.

## Usage

Use it when the user picks more than one value from a long list:

- Filtering results by several categories at once
- Assigning multiple owners, tags, or amenities
- Any set-valued field where the choices are known up front

For one value use `Combobox`. For a handful of options with no filtering, a
group of `Checkbox` controls is clearer than a dropdown.

`maxSelected` caps the selection; the remaining options become unselectable
rather than disappearing, so the user can see what they are trading away.

`onValueChange` receives both the values and the matching options, so the label
for each chip does not need a second lookup.

Removing a chip, or clearing every choice with the clear button, hands focus to
the field: the button pressed goes with what it removed. After a clear the
field's list stays closed, since the visitor cleared the choice and did not ask
for options; typing or an arrow key opens it.

The clear and open buttons are Combobox's: each as tall as the field, 44 at
touch density and 40 at compact, at the field's end in either direction. On
one line the field keeps its height. The buttons keep the field's end free, so
each line has 16px less room for chips than it had with the older 28px buttons
(4px less without the clear), and chips wrap that much sooner. A `className`
with `p-*` or `pe-*` replaces that space, and the chips and text then run
under the buttons, as text does on Combobox.

## Groups

Give options a `group` and they are listed under their groups (GAP-192), as Combobox
lists them: in the order the groups first appear, each under its label, drawn as
`SelectLabel` draws its own. Filtering keeps a group's label while any of its options
matches and drops it when none does. Each group is a `role="group"` named by its label;
the label is not an option, and the arrow keys move through the options in the order they
are drawn, never onto a label. SwiftUI and Compose do not group yet.

  return (

        options={categories}
        value={filters}
        placeholder="Add a category"
        emptyText="No categories match"
        onValueChange={setFilters}

  );

<script setup>
import { KozmosMultiSelect } from "@kozmos-ds/vue"
import { ref } from "vue"

const selected = ref([])
const categories = [
  { value: "food", label: "Food" },
  { value: "retail", label: "Retail" },
]

  <KozmosMultiSelect

    :options="categories"
    :value="selected"

}

fun FilterScreen(options: List<KozmosListboxOption>) {

## Accessibility

- Each chip carries its own remove button with an accessible name naming the
  value, so "Remove Food" is announced rather than "Remove".
- Backspace in an empty input removes the last chip, matching the behaviour
  keyboard users expect from token fields.
- Reaching `maxSelected` disables the remaining options rather than hiding them,
  and the limit is announced.
