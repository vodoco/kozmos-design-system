# NavigationItem

Reusable navigation row/item primitive for top navigation, side navigation, and compact rails.

<Story of={NavigationItemStories.Side} />

## Usage

<PlatformSnippets
    react={`
import { NavigationItem, Icon } from "@kozmos-ds/react";
export function Example() {
  return (
    <>
      <NavigationItem
        href="/explore"
        icon={<Icon name="search-md" />}
        selected
      >
        Explore
      </NavigationItem>
    </>
  );
}
    `}
    swift={`
import SwiftUI

KozmosNavigationItem(
label: "Explore",

) {

KozmosNavigationItem(
label = "Explore",
placement = KozmosNavigationItemPlacement.Side,
selected = true,
icon = { Icon(Icons.Default.Search, contentDescription = null) }
)
}
`}

## Rail

A rail tile stacks its icon over its label. Every rail tile's label is **11px on a 14px line**
and takes **up to two lines**, in both densities: one size for every tile, never some small and
some large. A label that needs a third line is cut at the end of the second.

The tile is **72px wide**, **64px** compact. A default tile is 72px tall whether its label takes
one line or two; a compact one is 64px, and 68px with two lines.

<Canvas of={NavigationItemStories.Rail} />

### A dashboard's rail

A web dashboard gives its rail tiles **96px** with `className="w-24"`, as BottomNavigation widens
its own tiles with `w-auto flex-1`. A 72px tile leaves its label 56px, and a word as long as
"Configuration" is 73px at 11px and still 67px at 10px, so no legible size fits it there. In
96px tiles each of these nine labels takes at most two lines and every tile stays 72px tall,
measured in Chromium, Firefox and WebKit, in narrow and wide fonts (SF Pro and Verdana among
them).

<Canvas of={NavigationItemStories.DashboardRail} />

The native rails keep their 72pt and 72dp tiles (64 compact) and the same two lines: iOS draws the
label in `caption2`, 11pt on 14pt lines at the default text size, and Android in `labelSmall`,
11sp on 14sp lines. Both grow with the reader's text size.
