# IconButton

IconButtons are used for actions that don't require a label, such as "flaging" or "liking" an item.

The React component uses the shared Button control radius (16px), not a circular
pill override. Its minimum hit target remains 44×44px. Always provide an
accessible label for the action.

## Counter

`counter` draws a count over the icon's top-end corner (GAP-197): the tours left on a help button,
unread notices. It is Kozmos's `Counter`, small, in the theme fill, not a `Badge`: Badge is a
status (decision 93), a `div` that hides its counter at `size="icon"`. Its bottom and start edges sit
2px past the button's centre, so it covers the same corner of the icon at every size and density,
and the top-left in right to left. In forced colours, where its fill is dropped, an outline keeps it
apart from the icon.

The count is read with the button's name: "Help, 3" by default, or in `counterLabel`'s words,
`` (count) => `${count} tours left` ``, so a product says it in its own language. The number drawn is
hidden from readers, so it is not read twice; a button named by its content (no `aria-label`) reads
the count from a visually hidden line instead. Pass `undefined`, not 0, to hide the counter.

import SwiftUI
import Kozmos

// An action with no words of its own. iconName is an SF Symbol's name, not
// a Kozmos icon's (KozmosIcon draws "home-line" as "house"), and the label
// is what VoiceOver says, as aria-label is on the web.
struct HomeButton: View {
    let goHome: () -> Void

    var body: some View {
        KozmosIconButton(iconName: "house", action: goHome)
            .accessibilityLabel("Home")
    }
}
`}
    kotlin={`
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Home
import androidx.compose.runtime.Composable
import com.kozmos.components.iconbutton.KozmosIconButton

// An action with no words of its own. The icon is an ImageVector, not a
// Kozmos icon's name (KozmosIcon's "home-line" draws Material's Home), and
// contentDescription is what TalkBack says, as aria-label is on the web.
@Composable
fun HomeButton(goHome: () -> Unit) {
    KozmosIconButton(
        icon = Icons.Default.Home,
        onClick = goHome,
        contentDescription = "Home"
    )
}
`}
