# DateRangePicker

The range adapts to its container width rather than the screen width: narrow
modules stack the individually labelled fields. The group heading names the range.
Each date's bounds respect both the sibling date and the caller's `min`/`max`.

A paired start and end date field for selecting a period.

## Usage

Use it wherever a span matters rather than a single day:

- Report and analytics ranges
- Booking and availability windows
- Filtering history by period

For one date use `DatePicker`. `DateRangePicker` is exported from the same
module and shares its validation and formatting behaviour.

On the web, values are ISO `YYYY-MM-DD` strings rather than `Date` objects, so
they survive serialization and carry no timezone of their own. Native uses each
platform's own date type — `Date` on SwiftUI, `LocalDate` on Compose — so
convert at the edges of your app rather than in the field.

`onRangeChange` fires when either end changes, including while the range is
incomplete — expect a value with one end still empty and do not treat that as
invalid input mid-edit.

## Accessibility

- Start and end are separate labelled fields, so each is announced on its own
  rather than as one ambiguous control.
- `min` and `max` bound both ends; an end before its start is reported through
  `error`, as a message rather than by colour.
- The range reads correctly in RTL because the two fields follow flow order.
