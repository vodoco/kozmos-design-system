# Route Summary

<Canvas of={RouteSummaryStories.Active} />

The `RouteSummary` serves as the primary bottom-anchored modal sheet during active turn-by-turn Wayfinding sessions. It safely structures ETAs, unit distances, and core routing logic into a distinct hardware-independent layer.

## React

```tsx
import { RouteSummary } from '@kozmos-ds/react';
import { PersonStanding } from 'lucide-react';

<RouteSummary
    etaText="7 min"
    distanceText="500 ft"
    state="active"
    transportModeIcon={<PersonStanding />}
    onEndRoute={() => prompt("End Route Confirmation")}
/>
```

## Navigation

Given a `destination`, the summary takes the navigation layout: the destination's name with End beside it in the danger outline, the time, distance and arrival on one row, and the caller's progress — a `RouteProgressRail` in the products — below. The estimate layout above is unchanged.
