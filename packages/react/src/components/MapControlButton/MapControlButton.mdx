# MapControlButton

Product/SDK map action with icon-only and labelled presentations. The localized
`label` is always the accessible action name; `stateLabel` communicates a
controlled state such as “Off” without relying on colour.

It wears the SDK's map-control surface (decision 40), the Tracking Indicator of
Pointr's Location Tracking Buttons (Figma `ce7phRJR1sCkH6zT8EMH8I`,
`434:31572`), and so does every map control built on it — the zoom pair, the
compass, the location control and the floor tile:

- a **48px square**, above the 44px touch target (its minimum width and height
  are 48px, and it grows with its words), with 12px at the sides once labelled
  and 8px above and below;
- the **page's own surface**, opaque, with the Control corner (16) and **no
  border** in any state;
- the **map controls' elevation**, three shadows (`shadow-map-control`,
  `--semantics-elevation-map-control`), and the SDK's 32px backdrop blur;
- a **24px mark**, 8px from the words, and the words **bold 16px on a 16px
  line**.

The surface is owned CSS (`kozmos-map-control`), so it holds in a host without
`@scope`; a class passed in `className` still wins over it.

## How an active control reads

A toggle's state is its tone, as the SDK's is. Leave `pressed` unset for a
control that is not a toggle — zoom, compass — and it keeps the ink. `false` is
a toggle that is off: the mark and the words grey (foreground/400). `true` is
one that is on.

`emphasis` decides what "on" looks like. `tinted` is the default: the map
surface stays, the mark takes the theme's blue (theme/600) and the words navy
(theme/1000), and nothing else changes — no edge and no other lift — because a
control over a map has to remain legible against the tiles behind it and a
solid fill hides the very thing it sits on. `filled` inverts the surface to the
Button's primary tier, for callers that want the heavier emphasis.

## A state that says it all

`labelPlacement="stacked"` sets the name over the state, two equal lines — the
SDK's "Focus⏎Off". `showLabel={false}` draws the state alone, for a state that
says everything: the SDK's "No Location" has no "Focus" over it. The name still
starts the accessible name — "Focus, No Location".

<Canvas of={Stories.StateAlone} />

`stateDescription` is said after the state and never drawn: what the words on
the control leave out. The location control's heading mode shows "On", as
following does, and a screen reader hears "Focus, On, map turns with you". It
comes after the words, so the name still begins with what a voice-control user
sees.

## Announcing a change, then getting out of the way

A map mode toggle rests icon-only. When its mode changes it widens to say which
mode it is now, holds long enough to be read, and collapses back — while the
mode it announced stays on.

Set `revealOnChange` and the control does this itself. It is a prop rather than
only a documented recipe because a developer reading the props, or clicking
through the controls above, should find the behaviour without being told it
exists.

```tsx
<MapControlButton
  labelPlacement="stacked"
  pressed={mode === "following"}
  revealOnChange
  stateLabel={mode === "following" ? "On" : "Off"}
/>
```

<Canvas of={Stories.RevealsOnChange} />

`revealDelay` covers a change that takes time to settle — a route being
recalculated, say — so the control reveals its new state once the work is done
rather than while it is still wrong. `revealDuration` sets how long it holds.

<Canvas of={Stories.RevealsAfterWork} />

For anything that is not this component, `useRevealOnChange(value, { duration,
delay })` is the same timing as a hook and returns whether the label should be
showing.

import { MapControlButton } from "@kozmos-ds/react";
import { LayersThree01 } from "@kozmos-ds/icons";

// A map toggle: grey while off, the theme's blue and navy while on. It rests
// icon-only and says its new state for a moment when it changes.
export function LayersToggle({
  showsLayers,
  onShowsLayersChange,
}: {
  showsLayers: boolean;
  onShowsLayersChange: (showsLayers: boolean) => void;
}) {
  return (
    <MapControlButton
      icon={<LayersThree01 />}
      label="Layers"
      labelPlacement="stacked"
      pressed={showsLayers}
      revealOnChange
      stateLabel={showsLayers ? "On" : "Off"}
      onClick={() => onShowsLayersChange(!showsLayers)}
    />
  );
}

import SwiftUI
import Kozmos

// A map toggle: grey while off, the theme's blue and navy while on. It rests

            systemImage: "square.3.layers.3d",

            labelPlacement: .stacked,
            revealOnChange: true,
            pressed: showsLayers
        ) {
            showsLayers.toggle()

}

import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.outlined.Layers
import androidx.compose.material3.Icon
import androidx.compose.runtime.Composable
import com.kozmos.components.mapcontrolbutton.KozmosMapControlButton
import com.kozmos.components.mapcontrolbutton.KozmosMapControlButtonLabelPlacement

// A map toggle: grey while off, the theme's blue and navy while on. It rests

@Composable
fun LayersToggle(showsLayers: Boolean, onShowsLayersChange: (Boolean) -> Unit) {
    KozmosMapControlButton(

        onClick = { onShowsLayersChange(!showsLayers) },

        stateLabel = if (showsLayers) "On" else "Off",

}
