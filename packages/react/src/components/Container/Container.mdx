# Container

Constrains content width and applies consistent horizontal insets.
Use `inset="window"` for viewport-responsive page padding and `inset="panel"` for fixed padding inside a narrow panel.

SwiftUI and Compose take the same `inset` (`.window`, `.panel`): it pads the sides only, `panel` 16 and `window`
16, 24 or 32 with the width the container is given. Left out, the native container pads every side by 16, as
it always has.
