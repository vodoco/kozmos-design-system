# Dialog

A window overlaid on existing content.

Web `DialogContent` keeps its dismiss target at least 44 pixels, reserves title clearance and scrolls long content within the viewport. Set `closeLabel` for a localized dismiss action. Keep titles and descriptions short; the dialog is not a replacement for a full-screen task. For controlled recovery without a persistent DialogTrigger, explicitly restore focus in `onCloseAutoFocus` to a surviving control after dismissal. A missing or removed trigger cannot restore itself. Native modal focus isolation and physical VoiceOver/TalkBack acceptance belong to the consuming host; a rendered overlay alone does not prove them.

## Recovery overlays

Use Core Dialog, IconButton and Button; do not draw a separate SDK modal or copy their interaction styles. Dialog's persistent close control is a Core IconButton. Keep the explanation specific, with one recommended action: choose a starting point when position is unavailable, or retry when the request can be retried. Never silently relax a step-free preference.

For short recovery choices, use `DialogFooter layout="stacked"`, put the primary Button first and a ghost Button such as “Explore map” last. This opt-in layout keeps visual, reading and tab order aligned, fills the available width and wraps long translations. The default `responsive` layout retains its existing desktop row/mobile reversed-column behavior for compatibility.

In controlled recovery, use `onOpenAutoFocus` to focus the non-destructive recommended action. On close, restore to the screen actually revealed: the starting-point input, map action, or enabled calculation-cancel control. Escape and the close button dismiss the message without discarding confirmed places. Do not remove keyboard focus rings to simplify the appearance.

See **Examples / Navigation journey** for five controlled failure states and actual callbacks. The stacked-footer prop and revised visual treatment are currently React-specific; the native APIs below support primary/secondary actions but do not yet expose this stacked layout. Do not treat a web preview as native modal parity.
