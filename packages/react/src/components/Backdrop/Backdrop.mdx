# Backdrop

A full-viewport scrim that visually separates foreground content from the page.
Use `visible` to toggle it; dialog semantics, focus management and dismissal belong to the enclosing overlay.

It is fixed and z-index 50, and it renders where it is placed: it does not portal itself. Inside
a `MapView`, which is its own stacking context, it covers the viewport but stacks inside the map,
under a sticky header and AdaptiveMapShell's chrome. Render it outside the map, or portal it out
(React's `createPortal`, into a `ThemeProvider` of its own).

## Target

A tour dims the page and lights the one control its step points at. Give `target` that control:
an element, a ref to one, a virtual element (anything with `getBoundingClientRect()`), a rect in
the viewport's coordinates, or a list of them lit as the one box round them all.

- The dim covers everything but the cut-out, which is padded by `targetPadding` (layout.spacing.100,
  8, by default) and rounded by `targetRadius` (radius.control, 16), and ringed 2px outside it in
  the focus colour. In forced colours the ring is a border in the system's Highlight.
- Pointer events pass through the cut-out, so the control can be pressed; the dim catches them
  everywhere else. The backdrop's own children, a step card, are never clipped by the cut-out and
  take the pointer over it too.
- The control is never moved or re-stacked: it stays where it is in the DOM and in its own
  stacking context, and nothing changes its z-index or style.
- The cut-out follows it as it resizes, as anything that scrolls it scrolls and as the window
  resizes, and, while it is lit, every frame: a control pushed by layout above it, or moved by a
  transform (a sheet still sliding in), is followed too, and a virtual element is read again each
  frame. It writes only when the cut-out moves. A ref is read every frame while the backdrop is
  open, so a control that comes later in the tree is lit once it is there.
- When the tour moves on to another control, the cut-out glides there over the standard duration,
  from where it was; under reduced motion it moves at once. A rect or virtual element that moves,
  a map point as the map moves, is followed, never glided to.
- A 0 by 0 virtual element or rect, a point on a map, is lit as a point: the cut-out is the
  padding round it, rounded to a circle.
- With no target, or one that is not there (a ref to nothing, an element with no box), the whole
  page is dimmed, as without `target`.

Nothing in the dim is focusable, and the ring is hidden from assistive technology: saying which
step this is, and what it lights, is the step card's job.

<PlatformSnippets
    react={`
import { Backdrop, Button } from "@kozmos-ds/react";
import { useRef } from "react";

export function Example() {
  const update = useRef<HTMLButtonElement>(null);
  return (
    <>
      <Button ref={update}>Update</Button>
      <Backdrop target={update} />
    </>
  );
}
    `}
    vue={`
<script setup>
import { ref } from "vue"
import { KozmosBackdrop, KozmosButton } from "@kozmos-ds/vue"

// A template ref: the harness lights the component's element.
const update = ref(null)
</script>

<template>
  <KozmosButton ref="update">Update</KozmosButton>
  <KozmosBackdrop :target="update" />
</template>
    `}
    swift={`
import SwiftUI
import Kozmos

// The scrim fills the space it is given, past the safe areas, so it goes
// under what it dims at the screen's root. A tap on it calls onTap: what
// that closes, and the overlay's focus and semantics, are yours.
struct DismissibleBackdrop: View {
    @Binding var isOpen: Bool

    var body: some View {
        KozmosBackdrop(visible: isOpen, onTap: { isOpen = false })
    }
}
`}
    kotlin={`
import androidx.compose.runtime.Composable
import com.kozmos.components.backdrop.KozmosBackdrop

// The scrim fills the space it is given, so it goes under what it dims at
// the screen's root. A tap on it calls onTap: what that closes, and the
// overlay's focus and semantics, are yours.
@Composable
fun DismissibleBackdrop(isOpen: Boolean, onClose: () -> Unit) {
    KozmosBackdrop(visible = isOpen, onTap = onClose)
}
`}
