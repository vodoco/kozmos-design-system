# Routing Input Group

<Canvas of={RoutingInputGroupStories.Default} />

Editable route points with stable IDs and controlled change, swap, add and remove callbacks. The host owns routing and resolved-place identity; changing text does not confirm a place.

Set each point's `label` to its localized field name, independently of `placeholder` and the current value. Without a label, the group names the first field Origin, the last Destination and intermediate fields Stop followed by their index. Localize `swapLabel`, `addPointLabel` and `removePointLabel` too. SwiftUI accepts the same named initializer arguments; Compose's localized overload accepts `KozmosRoutingInputLabels`, preserving existing positional and trailing-removal-lambda calls.

## React Usage

```tsx
import { RoutingInputGroup } from '@kozmos-ds/react';

<RoutingInputGroup
    points={[
        { id: '1', value: 'Reception' },
        { id: '2', value: '', placeholder: 'Add a specific Stop' },
        { id: '3', value: 'Marketing Department 4th Floor' }
    ]}
    onPointChange={(id, value) => console.log(id, value)}
    onRemovePoint={(id) => console.log("Removed: ", id)}
    onAddPoint={() => console.log("Add Point Request")}
/>
```

With two points and an `onSwap` callback, the group shows a two-way vertical swap button. Add is a separate action shown when `onAddPoint` is supplied; it is not replaced by Swap. Remove applies only to intermediate stops, not clearing an origin or destination.
