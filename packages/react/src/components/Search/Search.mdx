A search input with a leading search icon, optional field label and validation message.
Use Search for a form field; use SearchBar when you need a clear action and a trailing map-toolbar control.

## A clear button

`clearable` draws a clear at the field's end while it holds text, and not while the field
is disabled or read-only. Pressing it, or Escape in the field, empties the field through its
own `onChange`, calls `onClear`, sends the `search_cleared` analytics event (never the query)
and puts the focus back in the field. Escape in an empty field is left to what holds it, so a
dialog still closes. `clearLabel` names the button in the page's language; it is "Clear
search" unless you pass one. The browser's own clear stays hidden: it emptied the field
behind the product's back. SwiftUI and Compose take the same `clearable`, `clearLabel` and
`onClear`.

import Kozmos

    @Binding var query: String

## In Safari

`className` lands on the field. A utility class passed there styles it in Chrome, Edge,
Firefox and Safari 26.4, and is ignored in Safari 26.0 to 26.3, where the field keeps its
own look: those versions apply no `@scope` rule to an `<input>` (GAP-174), and Kozmos's
utilities are scoped. Use the props, the provider's `tokens`, an inline `style` or your
own CSS, and `wrapperClassName` for the layout around it. Guides › Platform support ›
Fields in Safari has the detail.
