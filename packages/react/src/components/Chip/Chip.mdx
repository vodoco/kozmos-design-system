# Chip

<Canvas of={ChipStories.Default} />

`Chip` presents compact filter, category, and removable selection values. Use it
when the item can be selected or dismissed; use `Badge` for passive metadata.

## React Usage

```tsx
import { Chip, ChipGroup } from "@kozmos-ds/react";
import { Utensils } from "@kozmos-ds/icons";

<ChipGroup>
  <Chip selected onClick={() => setCategory("all")}>
    All
  </Chip>
  <Chip icon={<Utensils />} onClick={() => setCategory("coffee")}>
    Coffee
  </Chip>
  <Chip onRemove={() => clearFilter("open")}>Open now</Chip>
</ChipGroup>;
```

### One choice of several

When the chips are one choice — "Whole airport / Terminal 2" — say so: give the
group `selectionMode="single"` and an `aria-label` that names the choice, and
each chip a `value`. The group is then a radio group: it is announced as one
choice, it has one Tab stop, and the arrow keys move the choice, in the
direction the ThemeProvider sets. A choice cannot be emptied by a second tap.

```tsx
<ChipGroup
  aria-label="Search in"
  selectionMode="single"
  value={scope}
  onValueChange={setScope}
>
  <Chip value="airport">Whole airport</Chip>
  <Chip value="t2">Terminal 2</Chip>
</ChipGroup>
```

Without it, each chip is its own toggle, which is right for filters that combine
("Vegan", "Halal") and wrong for a choice: two toggles read as two unrelated
buttons, each pressed or not.

## Android Jetpack Compose

```kotlin
import com.kozmos.components.chip.KozmosChip
import com.kozmos.components.chip.KozmosChipGroup

KozmosChipGroup {
    KozmosChip(
        text = "All",
        selected = true,
        onClick = { }
    )
    KozmosChip(
        text = "Open now",
        onRemove = { }
    )
}
```

## iOS SwiftUI

```swift
import Kozmos

KozmosChipGroup {
    KozmosChip(text: "All", selected: true) {
        // action
    }
    KozmosChip(text: "Coffee") {
        Image(systemName: "cup.and.saucer.fill")
    } action: {
        // action
    }
    KozmosChip(text: "Open now", onRemove: {
        // remove filter
    })
}
```
