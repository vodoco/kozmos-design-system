# Chip

<Canvas of={ChipStories.Default} />

`Chip` presents compact filter, category, and removable selection values. Use it
when the item can be selected or dismissed; use `Badge` for passive metadata.

## React Usage

```tsx
import { Chip, ChipGroup } from "@kozmos-ds/react";
import { Utensils } from "@kozmos-ds/icons";

<ChipGroup>
  <Chip selected onClick={() => setCategory("all")}>
    All
  </Chip>
  <Chip icon={<Utensils />} onClick={() => setCategory("coffee")}>
    Coffee
  </Chip>
  <Chip onRemove={() => clearFilter("open")}>Open now</Chip>
</ChipGroup>;
```

### One choice of several

When the chips are one choice — "Whole airport / Terminal 2" — say so: give the
group `selectionMode="single"` and an `aria-label` that names the choice, and
each chip a `value`. The group is then a radio group: it is announced as one
choice, it has one Tab stop, and the arrow keys move the choice, in the
direction the ThemeProvider sets. A choice cannot be emptied by a second tap.

```tsx
<ChipGroup
  aria-label="Search in"
  selectionMode="single"
  value={scope}
  onValueChange={setScope}
>
  <Chip value="airport">Whole airport</Chip>
  <Chip value="t2">Terminal 2</Chip>
</ChipGroup>
```

Without it, each chip is its own toggle, which is right for filters that combine
("Vegan", "Halal") and wrong for a choice: two toggles read as two unrelated
buttons, each pressed or not.

## Selected, to every screen reader

A chip with an action is a toggle, and says whether it is on: `aria-pressed` on the web, a
selected button to VoiceOver, and selected or not selected to TalkBack, following the state the
product keeps. A chip with no action is a tag, text and never a button, whatever its colours say.
`onRemove` adds a remove button beside the chip, never inside it, named "Remove" and the chip's
words: the chip's own press is always its action. Disabled, the chip and its remove are announced
as disabled, and neither runs.

Pass `removeLabel` to provide the complete translated name of the remove button on
React, SwiftUI or Compose. The fallback remains "Remove" followed by the chip's text.
On SwiftUI this is available in both initializers. On Compose the localized overload
requires `removeLabel`; the original positional signature and trailing `onClick`
lambda remain valid. The app supplies the translation; Kozmos does not choose a locale.

## Android Jetpack Compose

```kotlin
import androidx.compose.runtime.Composable
import com.kozmos.components.chip.KozmosChip
import com.kozmos.components.chip.KozmosChipGroup

// Filters that combine: each chip is its own toggle, and TalkBack hears
// whether it is selected. "Open now" can only be taken away.
@Composable
fun CategoryFilters(
    category: String,
    onCategoryChange: (String) -> Unit,
    openNow: Boolean,
    onOpenNowRemove: () -> Unit
) {
    KozmosChipGroup {
        KozmosChip(text = "All", selected = category == "all", onClick = { onCategoryChange("all") })
        KozmosChip(text = "Coffee", selected = category == "coffee", onClick = { onCategoryChange("coffee") })
        if (openNow) {
            KozmosChip(text = "Open now", onRemove = onOpenNowRemove)
        }
    }
}
```

## iOS SwiftUI

```swift
import SwiftUI
import Kozmos

// Filters that combine: each chip is its own toggle, and VoiceOver hears
// whether it is selected. "Open now" can only be taken away.
struct CategoryFilters: View {
    @Binding var category: String
    @Binding var openNow: Bool

    var body: some View {
        KozmosChipGroup {
            KozmosChip(text: "All", selected: category == "all", action: { category = "all" })
            KozmosChip(text: "Coffee", selected: category == "coffee") {
                Image(systemName: "cup.and.saucer.fill")
            } action: {
                category = "coffee"
            }
            if openNow {
                KozmosChip(text: "Open now", onRemove: { openNow = false })
            }
        }
    }
}
```
