# Stepper

Shows progress through a labelled sequence, marking earlier steps complete and one step current.
`currentStep` is zero-based; it displays progress rather than providing navigation or form validation.
A screen reader hears which step is current: it is `aria-current="step"` on the web, and selected,
the platform's own word, in VoiceOver and TalkBack, where each step is read as one item, its number and name together.

## Dots

A tour shows its progress as dots: `variant="dots"` draws one dot per step and no label. Done
dots are filled with the theme fill, the current one is the long one (20 by 8), so its shape says
it as well as its colour, and pending ones are foreground 500, 3:1 or more against the page, a
popover and the muted fill in both themes. In forced colours, done and current are the system's
Highlight and pending ones an outline.

Put a tour's dots on the page, a popover or the muted fill: those are the surfaces they are
measured on. On background-200 (`bg-secondary`) they fall under 3:1: the light theme's pending
dots read 2.59:1 there, and the dark theme's done and current ones 2.32:1.

The dots are a group whose name is the position, "Step 2 of 5" by default: give `positionLabel`
the product's words, as a function of the step (from 1) and the count, or as a template with
`{step}` and `{count}`. Each dot is a list item named by its step, and the current one is
`aria-current="step"`, as in the numbered stepper.

`variant` is the indicator's style alone; an orientation, and a status for each step, would sit
beside it (GAP-173).

import { Stepper } from "@kozmos-ds/react";

  <KozmosStepper :steps="steps" :currentStep="1" />
</template>
    `}
    swift={`
import SwiftUI
import Kozmos

// currentStep counts from 0: the steps before it are done, the ones after it
// to come. It shows progress only, and no step can be pressed.
struct RouteSteps: View {
    var body: some View {
        KozmosStepper(
            steps: ["Choose destination", "Review route", "Navigate"],
            currentStep: 1
        )
    }
}
`}
    kotlin={`
import androidx.compose.runtime.Composable
import com.kozmos.components.stepper.KozmosStepper

// currentStep counts from 0: the steps before it are done, the ones after it
// to come. It shows progress only, and no step can be pressed.
@Composable
fun RouteSteps() {
    KozmosStepper(
        steps = listOf("Choose destination", "Review route", "Navigate"),
        currentStep = 1
    )
}
`}
