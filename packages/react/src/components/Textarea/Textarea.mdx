# Textarea

A multiline text field with a label, validation message and optional character count.
The count's limit is a soft maximum; use the native `maxLength` prop only when input should be capped.

## In Safari

`className` lands on the field. A utility class passed there styles it in Chrome, Edge,
Firefox and Safari 26.4, and is ignored in Safari 26.0 to 26.3, where the field keeps its
own look: those versions apply no `@scope` rule to a `<textarea>` (GAP-174), and Kozmos's
utilities are scoped. Use the props, the provider's `tokens`, an inline `style` or your
own CSS, and `wrapperClassName` for the layout around it. Guides › Platform support ›
Fields in Safari has the detail.
