# User Location Marker (Blue Dot)

<Canvas of={UserLocationMarkerStories.Default} />

Shows a map position and optional heading. Supply these values from your map
adapter; the component does not query device location. The example rotates only
when requested, and the marker rings respect reduced-motion preferences.

React, SwiftUI and Compose draw the full marker alike, in both themes: an 18-unit
dot in the map marker's blue inside a white ring, a 64-unit halo and heading cone
and a 48-unit pulse tinted from that blue, and no shadow. The blue and the ring
are fixed so the dot stands apart from its ring, and from any map, in dark as in
light. The pulse's motion still differs: React's grows past the halo, SwiftUI's
and Compose's within it. Under reduced motion it holds still on all three, at 48
units and 30 %.

Use `compact` for the 18-unit location dot without halo, pulse or heading cone; its ring is the surface it sits on rather than white. Route rails compose this same marker rather than substituting a manoeuvre icon. The compact mode is available on all three platforms and does not schedule an animation.

## React Usage

```tsx
import { UserLocationMarker } from "@kozmos-ds/react";

<UserLocationMarker heading={45} showHeading={true} />;
```

## Android Jetpack Compose

```kotlin
import com.kozmos.components.userlocationmarker.KozmosUserLocationMarker

KozmosUserLocationMarker(
    heading = 45f,
    showHeading = true,
    // What TalkBack calls it, in the product's language.
    label = "User location"
)
```

## iOS SwiftUI

```swift
import Kozmos

KozmosUserLocationMarker(
    heading: 45.0,
    showHeading: true,
    // What VoiceOver calls it, in the product's language.
    label: String(localized: "User location")
)
```
