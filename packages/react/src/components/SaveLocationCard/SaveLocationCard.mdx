# SaveLocationCard

A prompt offering to keep a place in the user's saved locations, with routing
and note shortcuts.

## Usage

Use it where a place is worth returning to:

- After a search lands on a venue
- In a POI detail sheet, below the primary content
- Following arrival, when the user may want to save where they parked

Do not use it for generic confirmations. `Card` and `Alert` cover those; this
component is specifically about the saved-places relationship.

`isSaved` is controlled. The component does not track its own saved state, so
the toggle reflects whatever your store says — which is what keeps it correct
after a sync from another device.

import { useState } from "react";
import { SaveLocationCard } from "@kozmos-ds/react";

## Accessibility

- Saved changes the glyph and the label, not just the tint, so the state is
  never carried by colour alone.
- The toggle exposes its pressed state to assistive technology rather than
  relying on the label change alone.
- All three actions keep a 44px target.
