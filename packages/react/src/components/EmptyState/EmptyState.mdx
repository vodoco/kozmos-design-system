# EmptyState

<Canvas of={EmptyStateStories.Default} />

The `EmptyState` component is used to communicate a zero-results condition or an empty state of an interface securely across all platforms.

## React Usage

```tsx
import { EmptyState } from "@kozmos-ds/react";
import { Search } from "lucide-react";

<EmptyState
  icon={<Search />}
  title="No results found"
  description="Try adjusting your filter parameters to discover new locations."
/>;
```

## Android Jetpack Compose

```kotlin
import com.kozmos.components.emptystate.KozmosEmptyState

KozmosEmptyState(
    title = "No results found",
    description = "Try adjusting your filter parameters to discover new locations.",
    icon = { /* Icon Composable */ }
)
```

## iOS SwiftUI

```swift
import Kozmos

KozmosEmptyState(
    title: "No results found",
    description: "Try adjusting your filter parameters to discover new locations."
) {
    Image(systemName: "magnifyingglass")
} action: {
    EmptyView()
}
```
