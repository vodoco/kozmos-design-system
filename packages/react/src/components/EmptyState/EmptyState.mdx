# EmptyState

<Canvas of={EmptyStateStories.Default} />

The `EmptyState` component is used to communicate a zero-results condition or an empty state of an interface securely across all platforms.

## React Usage

```tsx
import { EmptyState } from "@kozmos-ds/react";
import { PlatformSnippets } from "../PlatformSnippets";
import { SearchMd } from "@kozmos-ds/icons";

<EmptyState
  icon={<SearchMd />}
  title="No results found"
  description="Try adjusting your filter parameters to discover new locations."
/>;
```

## A wait it explains

When the empty state is explaining a long wait, such as the assistant's download before it can run on
the device, `progress` draws how far it has got under the description and above the action: a label
that names the bar, an optional value in words, and the bar. React takes `value` from 0 to 100,
SwiftUI and Compose from 0 to 1, as each platform's Progress does; a value outside that is drawn at
the nearer end, and NaN as none done. Screen readers read the label as the bar's name and the words,
or the percentage, as its value: the bar is one element, so the label is not read again as text.

The bar does not announce itself as it moves. A screen reader says its new value only while its focus
is on the bar, so someone who has moved on hears nothing until they come back to it. Saying that the
wait is over is the product's job: announce it once, when it finishes, from a live region or with a
toast (`ToastProvider`), and then show what the wait was for.

<Canvas of={EmptyStateStories.DownloadProgress} />

```tsx
<EmptyState
  title="The assistant isn't downloaded yet"
  description="It works offline once it's on this device."
  progress={{ value: 40, label: "Downloading the assistant", valueText: "12 of 30 MB" }}
  action={<Button variant="outline">Back to search</Button>}
/>
```

```kotlin
import androidx.compose.runtime.Composable
import com.kozmos.components.emptystate.KozmosEmptyState
import com.kozmos.components.emptystate.KozmosEmptyStateProgress

@Composable
fun AssistantDownloading() {
    KozmosEmptyState(
        title = "The assistant isn't downloaded yet",
        description = "It works offline once it's on this device.",
        progress = KozmosEmptyStateProgress(0.4f, "Downloading the assistant", "12 of 30 MB")
    )
}
```

```swift
KozmosEmptyState(
    title: "The assistant isn't downloaded yet",
    description: "It works offline once it's on this device.",
    progress: .init(value: 0.4, label: "Downloading the assistant", valueText: "12 of 30 MB")
)
```

## A list in its body

`list` draws what to try, or what is to come, under the description (GAP-165): Map Content's "No Map
Content Found" lists the level, the filters and another name. Each item is one line, drawn as a
bulleted list from the leading edge of the 280 column, above any progress and the action, and read
in order: a screen reader hears a list of so many items, and `listLabel` names it. On React an item
may be the product's own inline content, such as a `Link`; SwiftUI and Compose take the items'
words. An empty list draws nothing. React's bullet is the list's disc marker, in a 20 column; SwiftUI and
Compose draw a typed "•" 8 before the words, so their words start about 13 in.

<Canvas of={EmptyStateStories.WithList} />

```tsx
<EmptyState
  icon={<SearchMd />}
  title="No Map Content Found"
  description="Nothing on this level matches your search."
  listLabel="What to try"
  list={["Check the building and level", "Clear the type filters", "Search by another name or an ID"]}
  action={<Button variant="outline">Clear filters</Button>}
/>
```

```kotlin
import androidx.compose.runtime.Composable
import com.kozmos.components.emptystate.KozmosEmptyState

@Composable
fun NoMapContent() {
    KozmosEmptyState(
        title = "No Map Content Found",
        description = "Nothing on this level matches your search.",
        list = listOf("Check the building and level", "Clear the type filters", "Search by another name or an ID"),
        listLabel = "What to try"
    )
}
```

```swift
import SwiftUI
import Kozmos

struct NoMapContent: View {

            description: "Nothing on this level matches your search.",
            list: ["Check the building and level", "Clear the type filters", "Search by another name or an ID"],
            listLabel: "What to try"

    }
}
```

## A tone

`tone` makes the empty state a card of its own in one of Tag's six emotions (GAP-213, decision 194):
`themed`, `neutral`, `success`, `danger`, `informative` or `alert`. "No Map Content Found" on Map Content is
the alert tone. The card is the emotion's quiet surface, edged 1 in the emotion's text colour as Tag's outline
is, at the container's radius, padded as the empty state always is. Its title, description, list and progress
words are the ink that pairs with the surface, 4.5:1 on it in both themes, and its icon is the emotion's text
colour on a disc of the page's colour, which reads 4.5:1 there as the emotion's text does on the page. The
progress bar and the action keep their own colours. With no `tone` it draws as it always has, on the page with
no edge. SwiftUI's and Compose's `KozmosEmptyState` take `tone`, a `KozmosEmotion`, and draw the same card;
`pnpm tokens:contrast:check` holds the words on each surface and the icon on its disc in both themes.
