# ImageCropper

An image framed to an aspect ratio (GAP-273): the frame is the box, and the image moves and scales under it. A client's
logo takes a square (MAP-32); a cover takes 16:9. The result is the frame as fractions of the image, never pixels: the
product crops, on its server or in a canvas.

## Moving and zooming

A pointer drags the image and two pointers pinch it. Under the frame, the zoom row has Zoom out, a zoom Slider in percent
and Zoom in, from 100% (the most of the image the ratio allows) to `maxZoom` (4 by default); `showZoomControls={false}`
leaves it out. The frame is one tab stop: the arrow keys move it by a tenth of itself and plus and minus zoom about its
middle. The arrows are physical in right to left too, because an image does not mirror.

## The result

`onCrop` hands back `{ x, y, width, height }`, each a fraction of the image's width or height from its top-left corner,
after every move or zoom. `onImageLoad` hands back the frame the image is first drawn in, which is no change: what to
apply when the person changes nothing. Multiply by the image's pixel size to crop. SwiftUI and Compose write the frame
they draw back to `crop` once it is drawn, for the same reason.
Pass `value` with `onCrop` to control the frame, or `defaultValue` to open on a frame the product kept; either is held
to the ratio and inside the image.

## In a dialog

The cropper has no Apply of its own: as a step, put it in a Dialog with Apply and Cancel, and keep the last `onCrop` for
Apply.

## Accessibility

- The frame is named by `label` ("Image frame") and described by `instructions`, which are read, not drawn.
- Each move or zoom is said in a polite live region, as `statusLabel` words it: "Frame 20% from the left, 10% from the
  top, zoom 125%." A drag is said once the pointer lets go; the zoom Slider says its own value.
- A zoom button at its limit is unavailable (`aria-disabled`), not disabled, so focus stays on it.
- Every word is a prop, in the product's language: `label`, `instructions`, `statusLabel`, `zoomInLabel`,
  `zoomOutLabel` and `zoomLabel`.
- On SwiftUI the frame is one VoiceOver element whose value is where it is: swipe up or down zooms, and the Move left,
  right, up and down actions move it. On Compose it is one TalkBack node, its state where it is, with Move and Zoom
  actions and the zoom as its adjustable value.

import SwiftUI
import Kozmos

// The client logo's crop step: a square frame. crop starts nil, the
// middle at 100%, and the cropper writes the frame it draws back, as

struct LogoCropStep: View {
    let logo: Image
    let logoSize: CGSize
    @State private var crop: KozmosImageCrop?

    var body: some View {
        KozmosImageCropper(
            image: logo,
            imageSize: logoSize,
            crop: $crop,

        )
    }
}

// The client logo's crop step: a square frame. crop starts null, the

// fractions of the image: the product crops. TalkBack reads the frame as

@Composable
fun LogoCropStep(logo: Painter) {
    var crop by remember { mutableStateOf<KozmosImageCrop?>(null) }
    KozmosImageCropper(

        contentDescription = "Client logo",
        crop = crop,
        onCropChange = { crop = it },
        aspectRatio = 1f

}
