# NumberInput

A numeric field with optional stepper buttons and `min` / `max` / `step`
clamping.

## Usage

Use it for bounded quantities the user reads as a number:

- Quantities, counts, and durations
- Percentages and thresholds in settings
- Any value where nudging by a fixed step is natural

Do not use it for identifiers that merely look numeric — phone numbers, postal
codes, card numbers. Those are strings; stepping them is meaningless and
clamping them corrupts the value. Use `Input` instead.

`onValueChange` reports `number | null`, not a string. `null` is an empty field,
which is distinct from `0` — check for it explicitly rather than relying on a
falsy test.

Set `showSteppers={false}` where the range is wide enough that clicking is
pointless, such as a year.

## Accessibility

- Steppers are real buttons with accessible names, reachable by keyboard.
- Arrow keys step the value; the field stays usable without the buttons.
- Clamping happens on commit, not per keystroke, so typing "12" into a field
  with `min={10}` is not rewritten to "10" after the first character.
