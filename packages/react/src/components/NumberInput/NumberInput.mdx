# NumberInput

A numeric field with optional stepper buttons and `min` / `max` / `step`
clamping.

## Usage

Use it for bounded quantities the user reads as a number:

- Quantities, counts, and durations
- Percentages and thresholds in settings
- Any value where nudging by a fixed step is natural

Do not use it for identifiers that merely look numeric — phone numbers, postal
codes, card numbers. Those are strings; stepping them is meaningless and
clamping them corrupts the value. Use `Input` instead.

`onValueChange` reports `number | null`, not a string. `null` is an empty field,
which is distinct from `0` — check for it explicitly rather than relying on a
falsy test.

Set `showSteppers={false}` where the range is wide enough that clicking is
pointless, such as a year.

## A unit

`unit` draws a unit inside the field after the value, "15 m", so the label stays plain. It is
never part of the value: `onValueChange` still sends a number. A screen reader hears it once,
after the value, as `unitLabel` when you give one ("metres") and as written when you do not.
It lies at the field's end, so it is on the left in a right-to-left page, and the text keeps
clear of it at any length.

## Accessibility

- Steppers are real buttons with accessible names, reachable by keyboard.
- Arrow keys step the value; the field stays usable without the buttons.
- Clamping happens on commit, not per keystroke, so typing "12" into a field
  with `min={10}` is not rewritten to "10" after the first character.

## In Safari

`className` lands on the field. A utility class passed there styles it in Chrome, Edge,
Firefox and Safari 26.4, and is ignored in Safari 26.0 to 26.3, where the field keeps its
own look: those versions apply no `@scope` rule to an `<input>` (GAP-174), and Kozmos's
utilities are scoped. Use the props, the provider's `tokens`, an inline `style` or your
own CSS, and `wrapperClassName` for the layout around it. Guides › Platform support ›
Fields in Safari has the detail.

## A mixed value

A number the selected features do not share is shown as "Multiple values" with `mixed`, until a typed
number edits it. The steppers are disabled while it is mixed, on every platform and in Figma: a step
would start from nothing and write that number over every selected feature's own. `onResetMixed`
offers "Reset to multiple values" once edited. Input's page has the whole of it (GAP-153).
