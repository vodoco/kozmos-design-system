# ClientAppBanner

Express's Client App Banner (GAP-127): a short promotion for the customer's
own app at the top of the map, with one action and a way to dismiss it.

Every field is set by the customer in Pointr Cloud, in the visitor's language,
and Kozmos draws them:

- **`promotionText`**, the line above the name: "Get the app";
- **`appIconSrc`**, the app's icon;
- **`appName`**, the app's name;
- **`description`**, what the app is for;
- **`actionLabel`** and **`onAction`**, the button: the product opens the
  store, or the app.

`onDismiss` adds a dismiss button. The banner never removes itself: the
product removes it, and decides for how long it stays away. Left out, there is
no dismiss button.

## Without an icon

Without an icon, or until it loads, the app's initial stands in for it, as an
Avatar's fallback does. The icon is 48 square with the Control corner and the
subtle edge, so an app icon on white still has an outline.

<Canvas of={Stories.NoIcon} />

## In the map shell's top bar

It is made for `AdaptiveMapShell`'s `topBar`. The top bar hosts what it is
given and draws no surface of its own, so the banner brings its own, as the
manoeuvre card there does: the solid surface (the page's fill and its subtle
edge), the Container corner (20) and map chrome's floating elevation. It is
16 inside, with the icon 12 from the words, and it fills the width the top bar
gives it.

<Canvas of={Stories.InShellTopBar} />

## Narrow widths

The words and the action share a line while the words keep 10rem (160 on
SwiftUI and Compose). Past that the action goes under the words, as wide as
they are. Nothing is measured on the web: a longer language, larger text or a
longer action moves it by itself. The description is drawn on two lines at
most; a screen reader still reads all of it.

<Canvas of={Stories.Narrow} />

Every side is logical: right to left, the icon and the words start at the
right, and the action and dismiss end at the left.

## Accessibility

- The banner is a **region named by the app** (`aria-label` names it
  otherwise). SwiftUI makes it a container labelled by the app's name, and
  Compose a pane titled by it that TalkBack reads as one group.
- It reads the **promotion, the name and the description, then the action,
  then dismiss**, on every platform and at every width, though dismiss sits
  above the words at the top end.
- The **action is named by its words** and nothing else, so what is seen is
  what is said (WCAG 2.5.3). The **dismiss button is named** by
  `dismissLabel`, "Dismiss" unless the product supplies its own words.
- The **icon is decoration** beside the app's name, and is not read. Pass
  `appIconAlt` only when the icon says something the name does not: it is
  then one image, loaded or not.
- Every target keeps **44** (48dp on Compose). Dismiss sits 4 from the top and
  end edges, its glyph in line with the words' 16.
- **Nothing moves focus** and nothing is announced. When the product removes
  the banner after a dismiss, it moves focus somewhere that makes sense, such
  as the search field: the dismiss button that had it is gone.

import { useState, type ReactNode } from "react";
import { AdaptiveMapShell, ClientAppBanner } from "@kozmos-ds/react";

// The customer's banner, as Pointr Cloud returns it, in the visitor's language.
interface AppBannerSettings {
  promotionText?: string;
  appName: string;
  description?: string;
  appIconUrl?: string;
  buttonText: string;
  storeUrl: string;
}

// Shown in the map shell's top bar until the visitor dismisses it.
export function MapWithAppBanner({
  banner,
  map,
}: {
  banner?: AppBannerSettings;
  map: ReactNode;
}) {
  const [dismissed, setDismissed] = useState(false);
  return (
    <AdaptiveMapShell
      map={map}
      topBar={
        banner && !dismissed ? (
          <ClientAppBanner
            promotionText={banner.promotionText}
            appName={banner.appName}
            description={banner.description}
            appIconSrc={banner.appIconUrl}
            actionLabel={banner.buttonText}
            onAction={() => window.location.assign(banner.storeUrl)}
            onDismiss={() => setDismissed(true)}
          />
        ) : undefined
      }
    />
  );
}
