# Checkbox

A control that allows the user to toggle between checked and unchecked states.

## Usage

Use checkboxes when:
- Users need to select one or more options from a list.
- Users need to toggle a single setting (e.g., "Accept Terms").

        onCheckedChange = onAcceptedChange,

## A description

A `description` is drawn under the label and read as the checkbox's description (`aria-describedby`), after its name and never as part of it (GAP-162). The label still toggles the checkbox; the description is words, not a target. SwiftUI reads it after the control's name; Compose reads it after the label, in the one node the row is.

<Canvas of={CheckboxStories.WithDescription} />

On SwiftUI the description is read after the name as the control's custom content, at high importance, spoken whether or not the reader turned on Speak Hints; its key, "Description", is looked up in your app's `Localizable` strings. The control says its state as its value, in `checkedLabel` and `uncheckedLabel` ("Checked", "Unchecked"; SwiftUI's checkbox takes a Bool, so it has no mixed state), and from iOS 17 it is a toggle. Compose reads the description after the label in the one node, and the checkbox says its state with its Checkbox role.
