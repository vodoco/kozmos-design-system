## Emotion

`variant` says how much a button weighs and what shape it takes. `emotion` says what it
means. They are separate axes because the product uses them separately: measured on
2026-09-14 across thirteen product surfaces, it drives six emotions and uses all six.

The token tiers already split the same way — `Components.Primary Buttons` is filled,
`Secondary` is bordered, `Tertiary` is text — and each tier has carried all six emotions
with `idle`, `hover`, `pressed` and `focus` since long before this prop existed. A variant
picks the tier; the emotion picks the colour inside it.

Colours are resolved from the active theme tokens, rather than fixed hex values.

`destructive` is already `danger`, by the values in the tokens. `glass` is an effect rather
than a weight and takes no emotion.
