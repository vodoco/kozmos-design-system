# Button

Buttons allow users to take actions, and make choices, with a single tap.

For a full-width action, React uses `className="w-full"`, Compose uses `Modifier.fillMaxWidth()`, and SwiftUI uses `KozmosButton("Done", fillsWidth: true) { ... }`. SwiftUI's opt-in expands the painted label and hit area, not just an outer container; existing buttons keep their intrinsic width by default.

## Emotion

`variant` says how much a button weighs and what shape it takes. `emotion` says what it
means. They are separate axes because the product uses them separately: measured on
2026-09-14 across thirteen product surfaces, it drives six emotions and uses all six.

The token tiers already split the same way — `Components.Primary Buttons` is filled,
`Secondary` is bordered, `Tertiary` is text — and each tier has carried all six emotions
with `idle`, `hover`, `pressed` and `focus` since long before this prop existed. A variant
picks the tier; the emotion picks the colour inside it.

Colours are resolved from the active theme tokens, rather than fixed hex values.

The default, filled and `themed`, is the theme fill: theme 500, the client's base colour set
in the Pointr Cloud Dashboard (`#135BEC`), in both themes, with white text on it in both,
5.62:1 (decision 59). Hovered it is `#1051E8`; focused from the keyboard `#1051E8` inside the
focus ring; and pressed, while the pointer holds it, `#0D44C2`, in both themes. Until
2026-10-07 the pressed and focus tokens were read by no rule, so a pressed button showed its
hover colour and a focused one its idle colour. Every filled emotion, and `destructive`, draws
its own four states the same way, stepping along its own ramp away from the page (decision 60):
hovered and focused one step, pressed two, darker in the light theme and lighter in the dark. The
dark neutral is the exception and keeps darkening, because white reads 3.72:1 on its lighter
step. Before decision 59 the fill was theme 700: in the dark
theme light blue (`#7EA2F6`) under black text, 8.39:1. Black on the new 500 would read only
3.74:1, which is why the text on it is white in both themes. `outline`, `ghost` and `link`
stay on the `Secondary Buttons` token, theme 700, which turns over with the theme: text on a
surface, not a fill.
