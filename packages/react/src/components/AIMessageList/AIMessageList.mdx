# AIMessageList

The thread: `role="log"` with `aria-live="polite"`, because turns arrive
over time and must be heard without taking the visitor's place. Polite, never
assertive — an assistant reply does not interrupt.

It follows the newest turn as it **grows**, not only as turns arrive: a
streaming reply writes into its own bubble without adding one, and a reply
below the fold has not been delivered. Set `followLatest={false}` when the
product scrolls the thread itself.
