# PropertyField

The frame every property of a Pointr Cloud item sits in (CLOUD-UI-004): a bordered group with the property's name as its caption, an info button that says what the property is, and a red trash button that removes it. A Dashboard module: it ships from `@kozmos-ds/react/dashboard`, with `@kozmos-ds/react/dashboard.css` loaded after the package's `style.css`, and only on the web.

## Named, every part

The group is named by its caption, so a screen reader says "Capacity, group" as focus enters it. The info button is named `About <name>` and opens its words on a click, Enter or Space, a toggletip a touch can reach as well; the remove button is `Remove <name>`, in Kozmos's destructive tone (`emotion="danger"`). Cloud's two buttons had no name. Give `infoLabel` and `removeLabel` in the product's language.

## Enum and Array properties

Select and MultiSelect take each option's value and label, and show the label, never the raw key ("underConstruction", "invite-only"), as the second and third properties above do. A chosen chip's remove button is named for its label, "Remove Invite only" (decision 177).

## A multi-selection

With several items selected whose values differ, every editor keeps their values and says "Multiple values" until it is edited (GAP-153): Input, NumberInput and Select with `mixed`, OpeningHoursEditor with `mixedDays`, RatingEditor with `mixed` per field, and KeyValueList with a row's `mixed`.
