This folder is what the Kozmos design-system artifact in Claude Design should carry, generated from this repository: how to consume the system (this page), and in [`components/`](components/) one card for each component `@kozmos-ds/react` 0.8.1 exports — the 116 in `packages/react/src/components` and the 3 providers beside them (`DesignConfigProvider`, `KozmosTheme` and `AnalyticsProvider`). A card lists every prop of every part as the built declarations give it, the Kozmos types those props take, and one example that compiles against them.

## Consuming this system

### Install

```bash
npm install @kozmos-ds/react react react-dom
```

`@kozmos-ds/react` 0.8.1 takes React `^18.2.0 || ^19.0.0` as a peer, and brings `@kozmos-ds/tokens` 0.4.0, `@kozmos-ds/icons` 0.5.0 and `@kozmos-ds/product-contracts` 0.7.0 with it.

### The stylesheet and the provider

- Import `@kozmos-ds/react/style.css` once. It holds the token variables for both themes and every component's styles, so there is no Tailwind configuration to add.
- Put everything inside a `ThemeProvider`. The styles are scoped to the provider's own part of the page: a component outside one is not themed, and most are not styled at all. `defaultTheme` takes `"dark" | "light" | "system"`, and `dir="rtl"` lays the provider's components out right to left.
- The scoping is CSS `@scope`, which sets the browser floor: Chrome 118, Edge 118, Safari 17.4, Firefox 146 and Android WebView 118.

### A minimal example

```tsx
import "@kozmos-ds/react/style.css";
import { Button, ThemeProvider } from "@kozmos-ds/react";

export function App() {
  return (
    <ThemeProvider defaultTheme="light">
      <Button>Take me there</Button>
    </ThemeProvider>
  );
}
```

## In the Claude Design artifact

These notes are about the artifact Claude Design builds from this repository, not about the npm packages.

- **The global.** The artifact's bundle, `components/bundle.js`, is one classic script that assigns `window.Kozmos`, the artifact's namespace. Every export a card names is a property of it: `Kozmos.POIResultCard`, `Kozmos.ThemeProvider`.
- **The load order.** An artboard loads `components/bundle.css`, then the page's own React 18 and ReactDOM 18, then `components/bundle.js`.
- **The provider.** Everything sits inside `Kozmos.ThemeProvider`, as in every card's example: outside it nothing is themed.
- **Mount, don't redraw.** Mount the real components with the Design editor's `x-import`, never lookalikes drawn from the tokens. An `x-import` takes the props the component's card lists, and the card's example shows the required ones.
- **The cards and the types.** Each `components/<Name>/README.md` in the artifact is this folder's `components/<Name>.md`, and `components/index.d.ts` is the package's built `dist/index.d.ts`.
- **The bundle is the artifact's own.** This repository publishes no script that assigns `window.Kozmos`. The package's `dist/kozmos-react.umd.cjs` assigns `window.KozmosReact` and expects each of its dependencies — the Radix primitives, framer-motion, the other Kozmos packages — as a global of its own, which no page provides.
- **Building it.** One IIFE named `Kozmos` from the package's ES build, `dist/kozmos-react.mjs`, with its dependencies inside it and `react`, `react-dom` and `react-dom/client` read from the page's `window.React` and `window.ReactDOM`. Bundle `react/jsx-runtime` from React 18, the page's React: React 19's runtime makes elements that React 18 refuses to render (its error #31). `components/bundle.css` is `@kozmos-ds/react/style.css` as it is.
- **Icons.** 16 of the cards' examples import icon components from `@kozmos-ds/icons` (AdaptiveMapShell, Alert and BottomNavigation among them), which `@kozmos-ds/react` does not re-export, so the artifact carries that package as well.

## Everything else `@kozmos-ds/react` exports

The hooks, helpers and constants that belong to no one component:

- `poiLocationLabel`: `(poi: { floorLabel?: string; buildingLabel?: string }) => string`. A POI's floor and building, joined the way every platform joins them.
- `useKozmosMapSync`: `(adapter?: MapSyncEngineAdapter) => { deriveTransform: () => string; scale: number; pitch: number; bearing: number; zoom: number; isMoving: boolean }`. A bridge hook uniting the Kozmos mathematical DOM overlays with WebGL camera pipelines (Mapbox/MapLibre).
- `useRevealOnChange`: `(value: unknown, { duration, delay, enabled }?: UseRevealOnChangeOptions) => boolean`. Reveals something for a while after a value changes, then closes it again.
