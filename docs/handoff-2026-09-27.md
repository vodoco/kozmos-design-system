## 9. Traps met today, with the evidence

- **A gate nobody runs is always green and never true.** `tokens:motion:check` had been reporting
  the sheet as reading no motion tokens — against a rule that read them perfectly — because its
  matcher was line-sensitive and prettier had wrapped the declaration. Nothing ran it. Fixed and
  wired into CI in #86.
- **A bare `1fr` grid track does not animate from nothing.** An `fr` track keeps an automatic
  minimum of its content, so the result card's action row jumped to 25px and grew from there.
  `minmax(0, Xfr)` states the zero. Found only by rendering it in a browser and sampling the
  animation; the gate now refuses a bare `fr`.
- **`overflow-x: auto` computes `overflow-y` to `auto` too.** A badge 2px proud of its button would
  have been clipped in FloorSelector's horizontal list. Found by reading the container, not by a
  test.
- **The geometry check runs on the built package.** A fix "verified" against a stale `dist` is not
  verified. Rebuild before `pnpm test:adaptive`.
- **`cmd | grep` reports grep's exit code.** An "EXIT=0" that way means nothing; redirect and test
  the command's own status.
- **Tailwind escapes its classes in `dist`** (`.-top-0\.5`, `.end-\[-2px\]`). A naïve grep reports
  false inerts.
- **A control that crashes proves nothing.** Guard a new harness section so a build without the fix
  reports failures rather than throwing on the first call.
- **A test can assert the defect.** Three assertions queried `{ pressed: true }` and had to change
  with #97.
- **iOS may already own the name you are about to take.** `ControlsPlacement` exists there and
  means something else (`.top` corner vs `.bottom` band); a React prop of that name meaning "which
  side" would have been worse than the bug it fixed.
- **`components:classes:check` needs a build first** — it refuses a stale stylesheet rather than
  answering for code that no longer exists.
