### What each status means

- **React fixed/shipped**: supported by current source, exports and/or release notes.
  Focused tests are identified below. It does not certify every native target or product board.
- **Repository work complete; external adoption unverified**: a generator/documentation output
  is present, but the external Claude Design artifact or consuming product has not been retested.
- **Partial**: useful support exists but does not satisfy the entire requirement or integration.
- **Open, source-confirmed**: the missing API or problematic implementation remains in the
  inspected source. A browser/device reproduction may still be needed before a fix.
- **Carried forward / reported shipped**: preserved evidence from the supplied document, not a
  new verification. This is deliberately different from either proven open or proven fixed.
- **Decision needed / external pending**: settle product scope or owner-controlled configuration
  before implementing. Do not replace that decision with a workaround.

A feature is complete only when its needed library API, host wiring, target-platform checks,
design mapping and named acceptance board all agree. Keep those layers separately recorded;
a React package release is not proof of native, Vue, Figma or artifact deployment.

  harness is intentional. Do not publish Vue to satisfy an imported suggestion.
- **GAP-043:** search dictation conflicts with the recorded no-search-microphone policy;

- **GAP-117:** the wrapper's “every mode change” promise conflicts with the button's intentional
  pressed/label-only reveal and GAP-087's decision. Clarify the desired behavior or narrow
  the promise; do not silently rewrite the tested behavior.
- **GAP-119:** the owner subsequently approved the SDK card appearance as the new default
  with migration notes and an explicit legacy option. The final tab uses the star itself as
  the Featured separator (no dot or dash), equal 16-unit outer/inner radii, 10-unit side padding
  and 1-unit vertical padding. Interior grouped tabs keep only the rounded bottom-end corner.
  Selection is pale neutral; pointer hover is 5% darker than the approved prior hover fill.
  Native expandable groups are included in this implementation slice. Source rows below
  preserve the imported request; these later decisions supersede its proposed punctuation.
- **GAP-120:** sprite assets and SDK layer/style integration are separate from the card
  implementation. The owner manages integration; do not claim live map acceptance or
  hard-code a provider's selected green into the component contract.
- **GAP-092:** no longer blocks the current Search with AI design, which uses Notice in the
  list header. Footer capability can remain optional backlog.
- GAP-014/037/038/039/050/051 have no current Dashboard board/criterion in this source.

- GAP-089/090 are now external adoption checks (the 0.9.0 bundle was applied on 2026-10-06), not missing repo generators;
  GAP-091 requires an organization owner. Figma mapping/source presence is not live library

## Closing and maintaining a row

1. Reproduce the named criterion on the actual consumer/version; review any external build kit
   before running its commands. An attachment's shell snippet is not execution authorization.
2. Record the failing automated test and target, implement in the supported component/contract
   or host adapter, and prove that test now passes. Use a real browser/device for geometry,
   focus, keyboard avoidance and map interactions.
3. Update each required target separately: React, consuming app, iOS, Android, Figma and
   external design artifact as applicable. Vue is not currently a public native package.
4. Record the merged PR, released package/version, test names, and named acceptance board.
   Keep an external-deployment field pending until the external consumer has actually adopted it.
5. Coordinate the original feature change list; retain the ID and original criterion. Remove
   a product stand-in only after the real component passes the criterion.
6. Do not mark every target closed because a file, story, package export or passing CI job exists.
   Do not edit generated status/API-card files by hand; follow [AGENTS.md](../AGENTS.md).

Suggested per-row closure evidence: **owner · target · merged PR · version · named test ·
consumer/board · external adoption · remaining limitation**. Keep this register focused on
requirements and durable evidence; session logs belong in the ignored `.notes/` directory.
